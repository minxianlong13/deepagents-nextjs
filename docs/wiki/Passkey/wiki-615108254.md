<p><span style="color: rgb(0,0,0);">RDK2 now ships with instrumentation endpoints that allow you to perform some in-place profiling in most pre-prod environments.  <em>Instrumentation is not available in prod or intg</em>.</span></p><p><span style="color: rgb(0,0,0);">The instrumentation suite provides you with 3 important endpoints that allow you to collect run-time memory snapshots from NodeJS.</span></p><p><span style="color: rgb(0,0,0);">These endpoints are built into RDK2, but can be copy/pasted into any NextJS-driven BFF application.</span></p><h1><span style="color: rgb(0,0,0);">Before You Begin Profiling</span></h1><p><span style="color: rgb(0,0,0);">You need to be aware that the new endpoints documented below 'stop the world' in order to allow you to perform these diagnostic tasks.  In one case in particular (Snapshot create), this can cause your target group health checks to fire a SIGKILL if it does not get heart beat responses for more than 30 seconds or so.  If you encounter this, you may need to reconfigure your target group:</span></p><ul><li><span style="color: rgb(0,0,0);">By default, 2 failed health checks cause a server restart.
