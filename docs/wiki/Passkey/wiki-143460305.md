Liquibase is a automation and source control tool for database instance, [https://www.liquibase.org/index.html](https://www.liquibase.org/index.html).

In current setup of devs,   there is no local db setup. Even if there is local db it is difficult to maintain since devs don't know exactly 

what applied to QAI, STG or any environment  any time and it is difficult to create same db from any environment as well as keeping update your local db.

  

Liquibase recognized this problem and introduced a systematic and automated way, which can be integrated to maven and other building tools, for applying database changes.

with Liquibase, you can apply multiple changes changes , changelogs, which consist of several sql files. Each change log file can have several change sets which can be written

in liquibase xml format or can references sql files. Change set can be configured to  run in a single transaction. Moreover, changelog files can be referenced from other changelogs file.

  

By this flexibility, devs can re-create  their local db from any environment or update their local db or track changes for some epic items.

For example, qai changes could be tracked by qai change log  and reference latest release and can be used to keep adding new changes
