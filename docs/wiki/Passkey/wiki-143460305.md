<p>Liquibase is a automation and source control tool for database instance, <a href="https://www.liquibase.org/index.html">https://www.liquibase.org/index.html</a>.</p><p>In current setup of devs,   there is no local db setup. Even if there is local db it is difficult to maintain since devs don't know exactly </p><p>what applied to QAI, STG or any environment  any time and it is difficult to create same db from any environment as well as keeping update your local db.</p><p><br /></p><p>Liquibase recognized this problem and introduced a systematic and automated way, which can be integrated to maven and other building tools, for applying database changes.</p><p>with Liquibase, you can apply multiple changes changes , changelogs, which consist of several sql files. Each change log file can have several change sets which can be written</p><p>in liquibase xml format or can references sql files. Change set can be configured to  run in a single transaction. Moreover, changelog files can be referenced from other changelogs file.</p><p><br /></p><p>By this flexibility, devs can re-create  their local db from any environment or update their local db or track changes for some epic items.</p><p>For example, qai changes could be tracked by qai change log  and reference latest release and can be used to keep adding new changes </p><p><ac:image ac:title="QAI CHANGE LOG" ac:alt="QAI CHANGE LOG" ac:height="250"><ri:attachment ri:filename="Screen Shot 2018-11-26 at 10.45.09 AM.png" /></ac:image></p><ac:structured-macro ac:name="code" ac:schema-version="1" ac:macro-id="a11d01ed-52d1-486c-aaf8-c76a96130a81"><ac:plain-text-body><![CDATA[{
