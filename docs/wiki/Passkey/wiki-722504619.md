# Overview

This document explores the experience (end to end) of:

-   Organizer creating a CW event with several hotels
-   Hotels learning about the event
-   Hotels retrieving their reservations from Passkey within that event

The goal is to look carefully at all interaction points and check for:

-   Unclear steps
-   Outdated terms or content
-   Use cases that are not supported well
