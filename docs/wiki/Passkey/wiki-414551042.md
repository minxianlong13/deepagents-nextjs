A number of Passkey applications support user-uploaded files, such as images and room-lists.  These files need to be scanned for potential malware before being used or stored in our systems.  [ClamAV](https://www.clamav.net/) is an open source malware scanner that has a simple [Java client](https://plugins.jenkins.io/clamav/#releases) that can be used to easily integrate in all our various applications.

Passkey uses a number of different software stacks for our web applications, and each had a slightly different way to integrate a malware scanner:

### Spring WebMVC

PlannerPortal uses spring-webmvc and supports dropping off room lists.  It was already configured with Spring's MultipartFilter, which will handle processing multipart requests and convert the HttpServletRequest to a MultipartHttpServletRequest.  Adding an additional filter after the MultipartFilter allows us to intercept the uploaded files and scan them before proceeding any further:

[https://stash.cvent.net/projects/PAS/repos/passkey-planners-ng/browse/src/main/webapp/WEB-INF/web.xml#25-41](https://stash.cvent.net/projects/PAS/repos/passkey-planners-ng/browse/src/main/webapp/WEB-INF/web.xml#25-41)

MultipartFilter org.springframework.web.multipart.support.MultipartFilter MultipartFilter /\* ClamAVFilter com.passkey.portal.web.filter.ClamAVFileUploadFilter ClamAVFilter /\* \]\]>

  

If a MultipartHttpServletRequest is provided to the ClamAVFileUploadFilter, the files are scanned.  In the event that a virus is found, the entire request is rejected (BadRequest) and the details logged.  
[https://stash.cvent.net/projects/PAS/repos/passkey-planners-ng/browse/src/main/java/com/passkey/portal/web/filter/ClamAVFileUploadFilter.java](https://stash.cvent.net/projects/PAS/repos/passkey-planners-ng/browse/src/main/java/com/passkey/portal/web/filter/ClamAVFileUploadFilter.java)

This approach applies malware scanning to _any_ file uploaded across the entire application.

### Struts 2.x

ResDesk uses a combination of Struts 2.x and 1.x, which required the changes listed above to support the Struts 1.x file upload actions, as well as a Struts 2 FileUploadInterceptor.  When the MalwareUploadInterceptor detected a virus in the upload, it would throw a MalwareException to be handled by the shared servlet to invalidate the session and deny the request.

  
[https://stash.cvent.net/projects/PAS/repos/passkey-resdesk/browse/web/src/main/resources/struts.xml#28](https://stash.cvent.net/projects/PAS/repos/passkey-resdesk/browse/web/src/main/resources/struts.xml#28)

The FileUploadInterceptor does not provide access to the original request when implementing the `acceptFile`  method to decide whether the file is safe.  In order to add support for this, a ThreadLocal variable was used to capture the request in the `intercept`  method, so it would be available for logging purposes.
