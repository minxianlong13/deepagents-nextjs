## Objective

The purpose of this document is to outline the requirements for redesigning the hotel event list page and objective of redesigning the hotel event list page is to enhance user experience and streamline the management of hotels within events. By revamping the current layout, our aim is to provide clear and intuitive access to essential information. Additionally empowering users to efficiently handle notifications and perform common actions. Through this redesign, we aspire to optimize the event management process, ensuring seamless coordination and improved usability for all stakeholders involved in planning and executing events and housing across various hotel venues.

## Features

Currently, the hotel event list page provides essential information including the hotel list, reservation access date, closure date, and event status (open/close). Additionally, it features an alerts section and a frequent tasks section with Quick notify, Event dashboard (Planner Portal), run reports, and Rezhub delivery.

## Background

The current hotel event list page serves as a vital tool for managing hotels within events. However, user feedback and usability assessments have revealed areas for improvement to enhance the overall experience and efficiency of hotel management.

**Alerts** 

-   Room list - Room list to be processed and redirects to the page where user can manage room lists for the event
-   Wait list - Reservations that are in the wait list
-   Group link setup - Signifies if the event needs group link setup and redirects to the setup page
-   Reservations that have no email address allocated
-   Unprocessed reservations - Redirects to the delivery status page showing information of unprocessed reservations
-   GroupMasterLink(GML) Events - Only applies to hotels and sister-property organizations that use the GML integration. It notifies the user of any inbound event messages that need to be approved. If Auto-Create was enabled and events were created based on GML messages, this alert will list any events that need an Event Type added.
-   Sub-Block Requests - Lists all the events with sub-block or public block requests that need to be reviewed.
-   Post Event Reports - Lists all the events with pending post-event reconciliation reports.
-   Inventory Requests - Lists all the events where inventory requests have been received by the hotel, inventory request responses need to be reviewed by the Citywide organizer, or the final inventory allocation needs to be confirmed by the hotel.

**Frequent tasks** 

-   Quick notify - This email template is used for any quick notes or last-minute changes or reminders directed to Booking Contacts.
-   Event dashboard - This redirects to the Planner Portal
-   Run reports - This redirects the user to reports section where all reports can be accessed 
-   RezHub Delivery - RezHUB is a reservation transfer tool that allows hotels to securely retrieve reservations for Passkey events.
