### 1 Deploy JReport locally

Use **java8**, **wildlfy10**, standalone config - [https://stash.cvent.net/projects/PAS/repos/passkey-jreport/browse/configs/dev-standalone-full.xml](https://stash.cvent.net/projects/PAS/repos/passkey-jreport/browse/configs/dev-standalone-full.xml)

Add oracle module

Make sure **/home/jreport** directory is either could be created or accessible.

Build and deploy artifact - [https://stash.cvent.net/projects/PAS/repos/passkey-jreport/browse/jreport/pom.xml](https://stash.cvent.net/projects/PAS/repos/passkey-jreport/browse/jreport/pom.xml)

It is not necessary to deploy actual reports - just start jreport server.

### 2 Generate new license file (jslc.dat)

Go to [http://localhost:8080/jreport/](http://localhost:8080/jreport/)

Login as **user**: admin | **password**: admin

Click Security under Manage

In the menu open **Configuration → License Key**

Update with values and **Submit**:

**User ID:** Passkey

**License Key:** <key> (usually provided in ticket e.g. - Cvent JIRAd1d78885-1a8e-3259-b68d-3df198ee3d46GROUP-81895)

After Submit license file should be generated - **/home/jreport/bin/jslc.dat**

To be sure - pay attention to modify time. It should be the same as submit time.

### 3 Update com.jinfonet:jboss7 dependency

Download the dependency - **jreport/passkey-jreport-ear/target/passkey-jreport-ear/lib/com.jinfonet-jboss7-<current version>.jar**

Re-pack jar updating the file **com.jinfonet-jboss7-<current version>.jar / jrenv.jar / workspace / bin / jslc.dat**

Upload updated jar to nexus under new version:

\\ -DgeneratePom=false \\ -Dpackaging=jar \\ -DrepositoryId=cvent-repo \\ -Durl=https://nexus.core.cvent.org/nexus/content/repositories/releases/ \\ -Dfile=com.jinfonet-jboss7-.jar\]\]>

Change version in pom.xml

Commit/Create PR

build - [https://ci-jenkins.core.cvent.org/job/Passkey\_Apps/job/passkey-jreport/](https://ci-jenkins.core.cvent.org/job/Passkey_Apps/job/passkey-jreport/)

deploy - [https://octo.core.cvent.org/app#/Spaces-1/projects/reports/deployments](https://octo.core.cvent.org/app#/Spaces-1/projects/reports/deployments)
