# Overview

The manual approval of provisioned block requests is a feature that opens a door to organizers into the air traffic control room of provisioning public requests. The original autoprovisioned request that was triggered with the "manual" approval setting creates everything in place but leaves several steps up to the organizer so that they can decline/edit/approve the request. In the approved workflow, RDK2 (representation layer for submitting requests from the organizer side) eventually needs to call several steps/endpoints. This document collects decision-making points for following one or another approach of allocation of aggregated calls execution. RDK2 GraphQL server or passing down to separate DW endpoint.
