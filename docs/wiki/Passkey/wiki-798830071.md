**Confusion about steps to take in Rezhub (integrated, non-integrated)**

  

  

CSA

  

**Hotel looking at unprocessed reservations doesn't clearly see changes to reservations**

RezHUB shows the reservations as unprocessed but doesn't show the changes made, only the error code.  The details do not show what was changed which makes it hard for hotels to decipher what the actual change is besides looking at all sections against the original booking.

  

 CSA

  

**Hotel is confused using RezHub if GL enabled**    

Essentially the ask is that the rezhub download button should not show for hotels that are GL enabled. This would prevent them from trying to download/upload a rooming list instead of utilizing GL Set Up as they should. Before hotels may have used this to download a rooming list with credit card information. But now that we don't have CCs on the rooming list there is no use case for pulling that from the download. If a GL hotel needs a full rooming list they should be using reports

  

 CSA

 

Hotel goes from licensed to unlicensed process issue

Need to know use case for licensed hotel to be able to download list (change wording.. make it a link, etc.)
