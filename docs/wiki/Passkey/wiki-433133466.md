<p><ac:structured-macro ac:name="toc" ac:schema-version="1" ac:macro-id="d2f5131a-36bc-4142-9502-c362ff1cdc0a" /></p><h1>Overview</h1><p>The magic link login to Passkey Autoblock request website flow allows extending access to auto-provisioned requests to the public with just entered email. Based on entered email Passkey service side will decide if the user exists (by extRecipientId) or is a new user. In the case of a new user, the service side will create extRecipientId and send a request for a magic link to Universal login.</p><h1>User scenario</h1><p><code><sub>Given an
