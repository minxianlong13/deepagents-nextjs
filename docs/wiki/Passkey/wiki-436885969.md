# Overview

\> This feature is to allow Organizers to publish the Auto Block requester website publicly and have any validated planner submit requests. The Planner in this text is the requester/coach persona.

The Public link functionality evolved from The Social Login, Magic Link and Universal Login use cases to a home backed solution that allows flexible integration with all existed applications and on top of it covers business use cases with open doors to future integration with PassCode and SMS text messages for providing user authority.

The project includes integration between several independent applications, including monolith Resdesk, Cvent Site-Designer Autoblock, AWS CDK, and downstream Dropwizard services.

# Business Rules

1.  Public users can't pass Public Link validation without entering contact info - email.
2.  HotLink has been valid for 1h since sending.
3.  Users are stored in Passkey DB for 1h and removed after if no requests have been submitted, if the request is submitted users become permanent users.
4.  Users can't send more than 3 HotLinks to the same email without submitting any requests for 24h
5.  Users get access to auto-provision requests if they click a valid link in an email client
6.  Users have to pass ReCaptcha validation before clicking send HotLink button.
7.  If users have all required data, the autoblock auto-provision flow skips the Contact Info step.
8.  If the user is coming from the public link HotLink, the email field is disabled on the Contact Info page.
