## Goals

-   Provide a way for event organizers to "see what their planners see" in Planner Portal for training and troubleshooting purposes.

## Background and strategic fit

Event organizers often need to train or assist their event-level planners or sub-block group contacts on how to use or interpret the Planner Portal. The easiest way to do that is to "see what the Planner sees."

Currently, if an event organizer (Hotel or Org user) accesses Planner Portal either by logging in directly or via the link on the Event Overview page in Manage, they see all events their hotel or org owns or participates in, which may be different than what specific event-level planners or sub-block group contacts have access to. Their permissions could be different as well.

Therefore, we want to:

1.  Get rid of the direct link to Planner Portal from the Event Overview page in Manage and disallow non-Sr. Org user types (anyone not an event-level planner or sub-block group contact) from logging in to Planner Portal. (Odyssey only supports the Sr. Org user type from logging in anyway)
2.  Add a link to the Event Overview page in Manage that links to the Multi-room Booking tool (MRB). Currenlty, MRB is only accesible via a link in Planner Portal
3.  Support the ability for certain user types to select an event-level planner or sub-block group contact to "impersonate" so that they temporarily have the same view of the Planner Portal as the person they have selected. This impersonation mode must be visually obvious in the Planner Portal UI (via banner or similar) and any actions taken on behalf of the person being impersonated must be logged.

## Assumptions

-   Only applies to Odyssey, not legacy Planner Portal (unless it's easier to incorporate into both)
-   Impersonating at event level only. Impersonator does not get access to event list (because they could see events owned by other owners)
