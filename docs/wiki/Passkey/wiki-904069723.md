The easiest way to do that is to &quot;see what the Planner sees.&quot;</p><p>Currently, if an event organizer (Hotel or Org user) accesses Planner Portal either by logging in directly or via the link on the Event Overview page in Manage, they see all events their hotel or org owns or participates in, which may be different than what specific event-level planners or sub-block group contacts have access to. Their permissions could be different as well.</p><p>Therefore, we want to:</p><ol><li data-uuid="d167ba83-93c4-43c0-8e94-435730e66b94"><ac:inline-comment-marker ac:ref="f37d29ba-415f-4f15-b110-d3e48764c337">Get rid of the direct link to Planner Portal from the Event Overview page in Manage and disallow non-Sr. Org user types (anyone not an event-level planner or sub-block group contact) from logging in to Planner Portal. (Odyssey only supports the Sr. Org user type from logging in anyway)</ac:inline-comment-marker></li><li data-uuid="aa2902a2-3b1c-43d0-b06d-051ab669773a"><ac:inline-comment-marker ac:ref="f37d29ba-415f-4f15-b110-d3e48764c337">Add a link to the Event Overview page in Manage that links to the Multi-room Booking tool (MRB). Currenlty, MRB is only accesible via a link in Planner Portal</ac:inline-comment-marker></li><li data-uuid="0efe0934-0ccb-40e7-8195-acc5b2660c8f">Support the ability for certain user types to select an event-level planner or sub-block group contact to &quot;impersonate&quot; so that they temporarily have the same view of the Planner Portal as the person they have selected. This impersonation mode must be visually obvious in the Planner Portal UI (via banner or similar) and any actions taken on behalf of the person being impersonated must be logged.</li></ol><h2>Assumptions</h2><ul><li>Only applies to Odyssey, not legacy Planner Portal (unless it's easier to incorporate into both)</li><li data-uuid="c27b6cb1-0132-44fd-9be5-ad0bebd7b013">Impersonating at event level only.
