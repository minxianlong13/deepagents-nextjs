## Goals

This wiki documents the areas of Passkey that use payment wallet to collect credit card data and how these will be changed to support:

1.  Ability to edit a _single_ credit card billing separately from credit card information
2.  Ability to _bulk edit_ credit card billing separately from credit card information

  

This is important so our customers can make changes without requiring the re-entry of full credit card information.  Especially useful in:

1.  Making corrections to an uploaded roomlist
2.  Call center agents helping attendees with reservation changes
3.  Planners or sub-block contacts using MRB to make reservation changes

The areas that need to be considered are:

-   RLM
-   Call Center
-   MRB
-   Booking Site
-   PBR
-   SBG Deposits

## Solution Outline

We will adjust the payment form in all channels / areas to separate out the "billing information" (address, phone, etc.) to make it possible to adjust this separately from credit card information.

This involves some minor UX changes that should eventually be applied to all areas where we collect credit cards.

## User interaction and design

For Multi-Edit reservations within the RLM workflow:

1.  If the user wants to bulk edit billing fields on any unprocessed reservations entered using a rooming list, and the reservations don't have a CC or address yet assigned to them, the user will be brought to a screen as such
2.  If user chooses Payment Type = Credit Card, currently the entire blank form for CC + Address fields appear.  We need to take the same pattern we used during single edits, and separate out this page into two editable sections

There is a secondary workflow for editing multiple reservations in the RLM
