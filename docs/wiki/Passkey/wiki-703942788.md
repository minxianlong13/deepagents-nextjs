Hotel-level taxes will have a null eventId.</p><p><br />EventProfile.HotelTaxAndFees stores the actual monetary details about the specific tax rate.</p><ul><li>AmountValue: The number value used in the calculation based on the next fields </li><li>CalculatedFromTypeId: Currently 2 values exist. Flat rate and Night rate. </li><li>CollectionScheduleTypeId: Currently 3 values exist. Per guest, Per room, Per night. </li><li>HotelTaxAmountTypeId: Currently two values exist. Amount or Percentage </li></ul><p><br /></p><p>Look up tables for the above Id's</p><ul><li>EventProfile.HotelTaxCalculatedFromType</li><li>EventProfile.HotelTaxCollectionScheduleType</li><li>EventProfile.HotelTaxAmountType</li></ul><p><br /></p><p><strong>**NOTE THESE ARE ALREADY INCLUDED IN THE ROOM RATE SO NOTHING NEEDS TO BE DONE WITH THESE FOR PHASE 1**</strong></p><p>EventProfile.Block and EventProfile.RoomType (Block and Room level) allows the setting of a fee based on the amount of guests added to a reservation. There are columns on both tables called AddPersonCharge, RoomRate3rd, RoomRate4th, RoomRate5thPlus that would get added to the base roomRate. In Passkey-Book this currently isn't broken down to show the additional guest fee. It just looks like a higher base room rate.</p><p><ac:image ac:height="250"><ri:attachment ri:filename="Screenshot 2024-08-07 at 9.02.15 AM.png" /></ac:image></p><p><br /></p><p><ac:image ac:thumbnail="true" ac:height="250"><ri:attachment ri:filename="Screenshot 2024-08-06 at 7.35.02 PM.png" /></ac:image></p><p><br /></p><h2>App Specific Information</h2><h3>Resdesk </h3><p>Event → Taxes <strong>AND </strong>Hotel → Taxes use the following stored procedure to retrieve tax info.</p><p><a href="https://stash.cvent.net/projects/PAS/repos/passkey-database/browse/TXN/DATABASE/SCHEMAS/ECOMMERCE/STORED_PROCEDURES/p_gethoteltaxstructure.sql#1,22,28">https://stash.cvent.net/projects/PAS/repos/passkey-database/browse/TXN/DATABASE/SCHEMAS/ECOMMERCE/STORED_PROCEDURES/p_gethoteltaxstructure.sql#1,22,28</a></p><p><a href="https://stash.cvent.net/projects/PAS/repos/passkey-database/browse/TXN/DATABASE/SCHEMAS/ECOMMERCE/STORED_PROCEDURES/p_savehoteltaxstructure.sql">https://stash.cvent.net/projects/PAS/repos/passkey-database/browse/TXN/DATABASE/SCHEMAS/ECOMMERCE/STORED_PROCEDURES/p_savehoteltaxstructure.sql</a></p><h3>Book</h3><p>Displayed Average Rate:</p><p>Hotel object has fields called minAvgRate and maxAvgRate used for display purposes.</p><p>Blocks object has averateRate and averageBasicRate field for displaying the average room rate. </p><p>HousingServiceImpl fetches hotels and blocks in the getAvailability function using stored procedures.
