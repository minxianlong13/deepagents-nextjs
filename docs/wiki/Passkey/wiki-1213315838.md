<h1>Context</h1><p>This page shows the results of a performance test on event-name search. The test compared two search strategies. The goal is to match a Passkey event to an event from an external system. The names may differ by typos, word order, or stop words.</p><p>Two search modes back two different UI flows:</p><ul><li><strong>Type 1 - Contains:</strong> finds an exact word anywhere in the event name. The system uses this first because it is faster.</li><li><strong>Type 2 - Fuzzy:</strong> uses word-level Jaro-Winkler (JW) similarity. Word order does not matter. The system uses this if Type 1 returns no results.</li></ul><p>Stop words (the, and, a, an, of, for, with, and &amp;) are stripped from the search phrase before the system builds a query. If all words in the phrase are stop words, the system does not send a query to the database.</p><h1>Data Model</h1><p>Event names are in <code>EVENTPROFILE.PARTICIPANT.NAME</code> (VARCHAR2 80) where <code>OBJECTTYPEID = 104</code>. Dates and status are in <code>EVENTPROFILE.EVENTINFO</code>. The column <code>PARTICIPANT_EVENTS.IS_OWNER = 1</code> links an event to its owner.</p><p>Two indexes exist on <code>PARTICIPANT.NAME</code>:</p><ul><li><code>IX_PARTNAME</code> - B-tree on UPPER(NAME)</li><li><code>IX_PART_NAME_FULL_TEXT</code> - Oracle Text CONTEXT index (supports CONTAINS())</li></ul><h1>Stop Word Handling</h1><p>Oracle Text <code>CONTAINS()</code> drops stop words automatically with its DEFAULT_STOPLIST. The words the, and, a, an, of, for, with, and &amp; each return zero hits when used alone. For the LIKE and UTL_MATCH strategies, the application must strip stop words before it builds the query.</p><h1>Test Corpus</h1><ac:structured-macro ac:name="info" ac:schema-version="1" ac:macro-id="6c396a0a-242c-4359-bd53-8f26508972d3"><ac:rich-text-body><p>Tests ran on <strong>sg50 (staging)</strong>.     private static final Set<String> STOP_WORDS = Set.of(
        "a","an","the","and","but","or","nor","so","yet",
        "at","by","for","in","of","on","to","up","as",
        "is","it","its","be","been","was","are","were",
        "with","from","that","this","these","those","not","&","vs","vs."
    );

    public static List<String> tokenise(String phrase) {
        if (phrase == null || phrase.isBlank()) return List.of();
        return Arrays.stream(phrase.trim().split("[\\s,;:()\\[\\]\"]+"))
            .map(t -> t.replaceAll("^[.\\-_/]+|[.\\-_/]+$", "").toLowerCase())
            .filter(t -> t.length() >= 2)
            .filter(t -> !STOP_WORDS.contains(t))
            .collect(Collectors.toList());
    }
}]]></ac:plain-text-body></ac:structured-macro><h2>EventNameSearchService.java</h2><ac:structured-macro ac:name="code" ac:schema-version="1" ac:macro-id="36e4c7ef-3942-4d21-a698-58d3005afd08"><ac:parameter ac:name="language">java</ac:parameter><ac:plain-text-body><![CDATA[@Service
public class EventNameSearchService {
    private final EventNameSearchMapper mapper;

    public List<EventNameSearchResult> containsSearch(EventNameSearchRequest req) {
        List<String> tokens = SearchTokeniser.tokenise(req.searchPhrase());
        if (tokens.isEmpty()) return List.of();
        String expr = tokens.stream().map(t -> "{" + t + "}").collect(joining(" AND "));
        return mapper.containsSearch(expr, req.ownerIds(), req.startDateFrom(), req.startDateTo());
    }

    public List<EventNameSearchResult> fuzzySearch(EventNameSearchRequest req) {
        List<String> tokens = SearchTokeniser.tokenise(req.searchPhrase());
        if (tokens.isEmpty()) return List.of();
        return mapper.fuzzySearch(tokens, req.ownerIds(), req.startDateFrom(), req.startDateTo(), 85);
    }
