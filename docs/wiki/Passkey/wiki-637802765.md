## Problem

The "Delivery Status" page in the Event is used mainly by CW organizers to check on reservations made, delivered, processed, etc.

  

-   **Hotel Name** - Clicking the hotel name will redirect you to the [RezHUB tool](https://support.cvent.com/Passkey/s/communityarticle/Using-Passkey-RezHUB).
-   **Total Reservations** - The total number of bookings made for each hotel participating in the event.
-   **Unprocessed** - The number of reservations that have this status in Passkey RezHUB.
-   **Last Login** - The date and time when a user associated with the participating hotel last accessed Passkey.
-   **Last updated by Hotel** - The name of either the last hotel user that logged into Passkey or the last hotel user who processed a reservation.
-   **Last Reservation Processed** - The last date and time when a reservation was successfully processed either manually or through GroupLink integration.
-   **Notification Email** - The email address set to receive hotel notifications.
