# Objective

The goal of this project to streamline and consolidate three separate pages into a unified platform, offering users a cohesive and efficient experience by presenting similar options for use in a centralized location and to seamlessly merge the Event Hotels List Page with the Delivery Status Page, while also incorporating comprehensive hotel details such as inventory dates, sell status, and policies into a unified Hotel Page. This integration aims to streamline the user experience, providing a centralized platform for event planning and hotel accommodation management. It would

-   Provide a consolidated view of event-related hotel list/bookings and delivery statuses.
-   Ensure seamless navigation between event details, hotel accommodations, and delivery statuses.

# Background 

The current product offers customers a range of options spread across various pages or screens, which could ideally be brought together into a single, consolidated interface. This consolidation aims to enhance user convenience and efficiency by presenting a unified interface where users can seamlessly navigate and utilize functionalities previously dispersed across multiple pages. The following screens are under consideration- 

users can view and manage in three separate places which includes :- 

-   Event → Event home 
-   Event → Reservations → Delivery status   - The "Delivery Status" page in the Event is used mainly by CW organizers to check on reservations made, delivered, processed, etc.  
-   Event → Advance options → Hotel  -  On this page, user can manage each participating hotel's inventory dates, sell status, description, child and cancellation policies, as well as tax disclosures. If the user is a Citywide event organizer, he can also add and remove hotels added to the event, request for new hotels to be added to the Passkey database, and view the profiles of participating non-licensed hotels.

## Terminologies

Term

Definition

Grouplink

GroupLink is an interface (API) that allows completed reservations to be transferred to a licensed hotel's Central Reservation System or Property Management System. This also automatically returns the hotel’s Confirmation Numbers into Passkey reservations.

RezHUB 

RezHUB is a reservation transfer tool that allows hotels to securely retrieve reservations for Passkey events. 

Property Management System (PMS)-

The system used by property staff to manage inventory, rates, housekeeping, front office, billing, etc. The Property Management System (PMS), meanwhile, manages all of the on-premises management needs (housekeeping, POS, check-in/check-out, etc.).

Central Reservation System (CRS)-

The system that connects the hotel to all distribution channels. Instead of connecting PMS to each channel separately (OTAs, GDS, Call center), the hotel connects to CRS, and CRS manages connectivity to all channels. The Central Reservations System (CRS) sits above the property level to manage and distribute Availability, Rates and Inventory (ARI) to guests via various channels.
