## Overview

Hotels need a cleaner way to set up email contacts for campaigns and automated GL reminders, and better GL status emails that are clear and compact. 

This wiki addresses the relevant areas:

1.  Setting up reservations contacts on Hotel profile page - for Hotel Welcome campaigns
2.  Setting up GroupLink specific contacts on GL profile page - for automated GroupLink emails
3.  GL setup summary email and IT contact error emails - improvements to content and layout

## Solution Outline

### Hotel Profile

#### Integrated Hotels

These hotels see a section like this. 

1.  The header and introductory text are not clear.
2.  Note also that "timing of reminders" is NOT shown, because that's on the GL Profile page instead.
3.  The field is not required, meaning that Hotel Welcome emails will NOT be sent if there's no email here, and the organizer wouldn't necessarily know this problem
4.  Also, there's no discussion of that separate GL Profile contact information that needs to be set up and maintained.

  

The content is partially dependent on the integration; it isn't universal - 

-   MHC/Rate Code --> Marriott
-   SRP --> Hilton
-   Block Code --> Opera, LMS, IHG

  

  

#### Non Integrated Hotels

These hotels see a section like this.

1.  The header and introductory text are not clear.
2.  The field is not required, meaning that Hotel Welcome emails will NOT be sent if there's no email here, and the organizer wouldn't necessarily know this problem

### GroupLink Profile

3.  Reminders -

**NOTE:** Currently _Second Email Reminder_ is not triggering email.

### Cvent Passkey GroupLink Status Summary

Email has a number of different problems we identified:

1.  Unprocessed Reservations
    1.  Intro text could be better
    2.  Information on event name, ID, and unprocessed res is too lengthy, not compactly stated
    3.  No links to actual event/rezhub to fix issues (although header is linked, and last sentence is linked to RezHub)
2.  Blocks Requiring Setup
    1.  Too wordy listing all blocks
    2.  No indication of actual problems
    3.  No link to GL setup page and ideally specific tab to take action
3.  Open Events Pending GL Setup
    1.  No event ID to clarify which event
    2.  Poorly formatted
    3.  Maybe needs additional sense of the problem?
    4.  Maybe needs open dates or start/end dates to help user prioritize?
4.  Inbound Reservations
    1.  Could table be better formatted, different headers, etc.?
    2.  Link at bottom is not helpful and needs to be adjusted
5.  General issues
    1.  Re-ordering of content could help
