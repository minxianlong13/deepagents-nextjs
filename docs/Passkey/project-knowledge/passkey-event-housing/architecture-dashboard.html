Passkey Event Housing Service

A Java 21 Dropwizard microservice that serves hotel, room, room-category, image, GroupLink and registration-connection data for Passkey events. Owned by team Metrestick. Everything on this page is taken from project-knowledge/, which was derived from source.

Architecture

Classic layered service with manual wiring in PasskeyEventHousingServiceApplication.run(). No DI framework.

ResourcesJAX-RS classes under resources/. Auth via @Authority(API_KEY); /images/pfu forwards the caller's Bearer token instead.
ServicesBusiness logic under service/. Providers in the same package wrap downstream clients and fail the request on error.
DAOsAbstractDao subclasses join the ThreadLocal session from executeInSameDbSession. Connection, Admin, GroupLink and RoomCategories DAOs use the raw session factory.
MappersMyBatis XML with Oracle MERGE upserts and PL/SQL blocks; IN lists chunked at 1000.
ErrorsEventHousingBaseException + mappers produce ErrorResponse {errorCodeType, httpRequestId}. Image endpoints return plain-text errors.

Database

Oracle tables referenced by mapper XML. No DDL in the repo, so relationships are inferred (Confidence Medium).

Main schemas

  • EVENTPROFILE: participants, participation, room types, blocks, room categories
  • XFER: GroupLink transfer definitions, mapping values, block transfer state
  • BRIDGE: registration access codes and partner associations
  • GUI: S3 image metadata, business text

Write rules

  • Upserts use MERGE, so most writes are re-runnable
  • Image delete and renumber share one session
  • Connection link and delete run in one explicit transaction
  • GroupLink setup commits each statement separately
