# Setting Up Deposit, Processing, and Cancellation Fees

If a [merchant account has been added](https://support.cvent.com/s/communityarticle/The-Complete-Guide-to-the-Merchant-Account-Processing-Feature-in-Passkey) to your organization's Passkey profile, you can use it to set up advance deposit, processing, and cancellation fees in your Passkey event. Here's how

**NOTE:** Before proceeding, [review the limitations](https://support.cvent.com/s/communityarticle/What-are-the-limitations-of-using-the-Merchant-Account-Processing-feature-in-Passkey) of using the Merchant Account Processing feature in your event.

  
**1 Select the merchant account you need.** Begin by selecting your Passkey event. From the Event navigation, click **Advanced Options**, then **Guarantee Types**.

Or, if your Passkey account has access to [guarantee rules](https://support.cvent.com/s/communityarticle/Passkey-Guarantee-Rules), click **Event Home**, then **Guarantee Types** in the Event navigation.

Click **Select Merchant Account**.

Choose the account you want and, if necessary, edit the text that will be shown on the credit card statement.

Click **Select**.

**2 Select the accepted credit cards.** On the Guarantee Types page, click **Manage**. Check the boxes next to the credit cards accepted for the event, then click **Save**.

**3 Set up deposit, processing, and cancelation fees.** Click the name of the desired [guarantee type](https://support.cvent.com/s/communityarticle/Configuring-Guarantee-Types-in-Passkey-Events) to access its settings. You can use the Deposit, Processing and Cancellation Fees sections within the guarantee type to configure complex payment plans.

If necessary, select the desired deposit type from the dropdown menu. To set up a processing fee, begin by selecting the fee model from the dropdown. Optionally, enter a custom processing fee name and outline the fee disclosures. The Custom Fee Name field allows up to 32 characters, and the Processing Fee Disclosure field allows up to 500 characters.

Processing fee information will appear in [various places](https://support.cvent.com/s/communityarticle/Where-are-processing-fees-displayed) across Passkey, such as the booking website, call center form, or communication emails. [Reference this article](https://support.cvent.com/s/communityarticle/When-are-processing-fees-charged-in-a-Passkey-event) to learn when processing fees are charged.

**NOTE:** You can only set up one deposit and processing fee per guarantee type.

To set up a cancellation rule, select the date when a cancellation fee should start being charged. The fee will be charged for cancellations performed from 12:01 AM onwards in the [event's time zone](https://support.cvent.com/s/communityarticle/Configuring-Time-Zones-in-Passkey#Event).

Select the desired option from the "Cancellation Fee as of Start Date" dropdown to specify the fee amount or how the fee will be calculated.

If you want to create a tiered cancellation rule, click **Add Cancellation Fee**.

**NOTE:** Cancellation fees are not cumulative.

Enter the final date when fees should be applied for cancellations. This date should be on or before the [reservation close date](https://support.cvent.com/s/communityarticle/Key-Dates-and-Times-in-Passkey-Events#PK_Details_ResDates). Consider the use of two-way GroupLink integration when setting this date. 

Click **Update** to auto-generate a cancellation fee disclosure message based on the cancellation rules you set up. If necessary, make edits to the disclosure message, then click **Save**. The cancellation fee disclosure will be displayed on the [booking website](https://support.cvent.com/Passkey/s/communityarticle/The-Complete-Passkey-Booking-Site-Experience)'s Summary page.

**NOTE:** While cancellation fees can be edited at any time, guests who cancel their reservation will be charged based on the cancellation fee that was valid at the time they created the booking.
