# Can a registrant book several rooms for an event integrated with Passkey?

FAQEvent ManagementPasskey

The [integration between Passkey and Registration](https://support.cvent.com/s/communityarticle/The-Complete-Guide-to-Integrating-Events-with-Passkey) supports a one-to-one mapping between a room reservation and a registration record. If a registrant books several rooms through Passkey, only one room will be synced back to their registration record. We therefore recommend configuring the Passkey attendee types to [only allow one reservation per session](https://support.cvent.com/s/communityarticle/Configuring-the-Number-of-Reservations-per-Session-by-Attendee-Type).
