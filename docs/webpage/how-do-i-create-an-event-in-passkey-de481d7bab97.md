# How do I create an event in Passkey?

If your organization or hotel has purchased a Passkey license, you can create housing events to manage room blocks and reservations. Begin by clicking **Create new event** on the [Passkey Home page](https://support.cvent.com/s/communityarticle/Using-the-New-Passkey-Home-Page). Enter your event name, type, and date range. You can select a date range of up to 365 days. Click **Select** next to the desired event creation method:

-   [Use an existing bundle](https://support.cvent.com/s/communityarticle/Using-a-Bundle-to-Create-a-Passkey-Event) - A bundle acts as a template you can build your new event on. If you choose this method, you will be prompted to select the bundle you want from the dropdown.
-   [Create your event from scratch](https://support.cvent.com/s/communityarticle/Creating-a-Passkey-Event-without-a-Bundle) - Choose this method to individually configure the event settings and pick the library elements you want to include in your event. Since no template is used, this method is more time consuming.
-   [Copy an existing event](https://support.cvent.com/s/communityarticle/Copying-an-Event-in-Passkey) - Choose this method to create an event that needs the same configuration as a previous one you organized.

Click **Create event**, and proceed to configuring your event settings.

**NOTE:** If your hotel or sister property organization is using the [GroupMasterLink integration feature](https://support.cvent.com/s/communityarticle/About-GroupMasterLink), you can [create Passkey events](https://support.cvent.com/s/communityarticle/Creating-a-Passkey-Event-with-GroupMasterLink) based on groups already set up in your hotel property management or central reservation system.
