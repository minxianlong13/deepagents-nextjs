# Cancelling a Passkey Event

InstructionsPasskey

If you change your mind or if you created a Passkey event by accident, follow the steps below to cancel it.

**1 Cancel any existing reservations within the event.** If reservations have already been made for the event, we recommend you cancel them prior to cancelling the event. You can either [cancel them individually](https://support.cvent.com/Passkey/s/communityarticle/Using-the-Call-Center-Form-to-Modify-or-Cancel-a-Passkey-Reservation) or [in bulk](https://support.cvent.com/Passkey/s/communityarticle/Using-the-Multi-Room-Booking-Tool#BulkCancel).

**2 Cancel the event.** From your event's left-hand navigation, click **Details**, then **Details** again. Click **Cancel Event** in the bottom right. Carefully read the message in the next prompt and click **OK** when you're done. 

![User-added image](https://support.cvent.com/servlet/rtaImage?eid=ka02G000000LzCk&feoid=00N2G00000CxUw1&refid=0EM2G000001Z9fC)

  
Once an event is cancelled, all the communication emails (campaigns, acknowledgements, and SmartAlerts) will be automatically turned off. The booking website can still be accessed, but will display a [closed event message you can customize per your needs](https://support.cvent.com/Passkey/s/communityarticle/Managing-Text-Elements-on-the-Passkey-Booking-Website).
