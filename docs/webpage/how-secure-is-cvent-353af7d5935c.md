# How secure is Cvent?

At Cvent, we take a comprehensive approach to securing your data. This includes:  

 

-   **Compliance** - Cvent has obtained various compliance certifications, including PCI DSS, SOC 2 Type II, ISO 27001, GDPR, and CCPA, which demonstrate our commitment to data security.
-   **Access Controls** - Cvent has strict access controls to ensure that only authorized personnel can access sensitive data.
-   **Disaster Recovery** - Cvent has recovery measures in place to ensure that customer data is always available in case of a disaster or system failure.
-   **Cloud Storage and Data Protection** - Cvent utilizes Amazon Web Services (AWS) to host customer data across all products, and employs various network security measures such as intrusion prevention systems (IPS), intrusion detection systems (IDS), and web application firewalls (WAF), to establish multiple layers of protection. Additionally, Cvent implements a comprehensive set of security protocols designed to effectively safeguard its infrastructure against both internal and external threats.
-   **Secure Applications** - Customer data is encrypted at rest via AES-256 and transmitted using 256-bit Transport Layer Security (TLS) protocol, supporting up to version 1.2. All passwords are also protected by salting and storing it with one-way hashing. This means each password has a randomized string attached to it, then an algorithm is used to convert the password into a fixed string of characters. All websites under the [cvent.com](https://www.cvent.com/) domain enforce HTTPS by default. Any attempts to connect over HTTP are automatically upgraded to HTTPS.
-   **Secure Payments** - Cvent is certified Level 1 compliant to the PCI Data Security Standards (DSS). This means we've undergone an onsite audit by a third-party Qualified Security Assessor. You can even download our PCI DSS AOC certificates for Cvent Core and Passkey from [here](https://trust.cvent.com/). All payment processing is hosted on HTTPS pages. Any financial report generated in Cvent will only show the last four digits of registrants’ card numbers. Accounts with multiple users can further control who sees what.

For additional information, reference the [Cvent Trust Center](https://trust.cvent.com/).
