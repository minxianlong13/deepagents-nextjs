# Enabling RegLink in a Passkey Event

Watch the video or follow the steps below to connect your Passkey event with a registration provider that supports [RegLink integration](https://support.cvent.com/s/communityarticle/About-RegLink).  

Adding Registration Providers

**1 Add a registration provider.** Begin by selecting your Passkey event. From the left-hand navigation, click **Details**, then **API Access**. Click **ADD A PROVIDER**.Use the available filters to search for the provider. Check the box next to the one you need and click **Add Selected Providers**.

   ![Add a Provider page, with a provider selected from the search results list. The "Add Selected Providers" button is highlighted.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui000000H3Xl&feoid=00N2G00000CxUw1&refid=0EM2G000001Yzr8)

  
**2 Enable RegLink.** To enable the newly added provider, toggle RegLink to **ON**.  
 

   ![API Access page with one registration provider added and enabled.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui000000H3Xl&feoid=00N2G00000CxUw1&refid=0EM2G0000024XJ2)  
 

If the provider has any [default callbacks](https://support.cvent.com/s/communityarticle/Enabling-Default-Callbacks), you will be prompted to enable them.  
 

**NOTE:** If the registration company or platform is Convention Data Services (CDS), [create a case](https://support.cvent.com/s/createcase) to have Joint Confirmations enabled.

If no default callbacks are found, you can [manually add them](https://support.cvent.com/s/communityarticle/Adding-Callbacks-for-Reglink). 

Finally, click the ![RegLink Event Code arrow](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui000000H3Xl&feoid=00N2G00000CxUw1&refid=0EM2G000001ZKH6) icon next to Event Codes and provide your registration partner with the event information and codes they might need in order to connect the registration event with the Passkey event.

Adding Event Connection Codes  
Third-party registration systems that support Passkey's next-generation RegLink APIs can connect with a Passkey event by using connection codes. Follow the steps below to learn how.

**1 Access the Event Connection Codes section.** Begin by selecting your Passkey event. From the left-hand navigation, click **Details**, then **API Access**. Click the ![Callback setup arrow](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui000000H3Xl&feoid=00N2G00000CxUw1&refid=0EM2G000001Z9dQ) icon next to Event Connection Codes to expand this section.

Any existing event codes will appear in this section and will display information about the associated event planner or registration system provider. 

![Event Connection Codees section, with one code added.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui000000H3Xl&feoid=00N2G00000CxUw1&refid=0EM2G000001Z9dk)

**2 Add a connection code and associate a planner to it.** Click **Add Code**. A unique alphanumeric code will be automatically generated on the event connection codes list. Its initial status will show as Approved, meaning it is ready to be used by an event planner to connect to a registration system provider.

Click the ![Menu options](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui000000H3Xl&feoid=00N2G00000CxUw1&refid=0EM2G000001Z9dp) icon next to the newly generated code and select **Add planner**.

If there are event planners already assigned to your event, you can choose the one you want to associate to the connection code by clicking **Select** next to their name.

![](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui000000H3Xl&feoid=00N2G00000CxUw1&refid=0EM2G000001Z9du)

  
Decide if you want to send a notification email to the selected planner, then click **Add planner**.

To add a planner that isn't currently assigned to your event, click **Create new planner**. Enter the planner details such as the email address, name, company, phone number, and preferred language. Decide if you want to send them a notification email, then click **Create planner**.

![Create New Planner prompt, with the planner details filled in. The "Create Planner" button is highlighted.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui000000H3Xl&feoid=00N2G00000CxUw1&refid=0EM2G000001Z9dz)

  
**Or add a connection code to a planner profile.** Begin by selecting your Passkey event. From the left-hand navigation, click **Planners**, then **Planners** again. Click the ![Edit](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui000000H3Xl&feoid=00N2G00000CxUw1&refid=0EMUi000001cldF) icon next to the planner you need.In the Enable API Access section, click **Add event connection code**. A unique alphanumeric code will be automatically generated.

Click **Save**. 

Once the code is successfully used to connect the Passkey event to a registration system provider, it will display a Connected status on the API Access page.
