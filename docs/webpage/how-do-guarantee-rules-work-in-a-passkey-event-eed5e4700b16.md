# How do guarantee rules work in a Passkey event?

If you've [enabled and set up guarantee rules](https://support.cvent.com/s/communityarticle/Passkey-Guarantee-Rules) for a Passkey event, guarantee types will be assigned based on the hotel an attendee selects, rather than the attendee type.

When a new reservation is being created through any reservation channel, Passkey will check if there is a guarantee rule configured for the hotel selected during the booking process. If a rule exists for the selected hotel, Passkey will apply the guarantee type associated with the rule. If no rule is configured for the selected hotel, Passkey will apply the guarantee type associated with the [default guarantee rule](https://support.cvent.com/s/communityarticle/Passkey-Guarantee-Rules#Default) instead.

For existing reservations, Passkey will only check for and apply the appropriate guarantee rule if the reservation is [moved from one hotel to another](https://support.cvent.com/s/communityarticle/Moving-Reservations-Between-Hotels-in-a-Citywide-Event) before the [reservation access date](https://support.cvent.com/s/communityarticle/Key-Dates-and-Times-in-Passkey-Events#PK_Hotel_inv_dates). Any other changes to an existing reservation, such as cancelling it or updating the attendee type, room type, stay dates, or billing information, will not affect the guarantee type associated with the reservation.
