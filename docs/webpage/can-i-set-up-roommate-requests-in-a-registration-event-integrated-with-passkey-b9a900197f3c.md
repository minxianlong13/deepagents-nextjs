# Can I set up roommate requests in a Registration event integrated with Passkey?

FAQEvent ManagementPasskey

No. If your [Registration event is integrated with Passkey](https://support.cvent.com/s/communityarticle/Setting-Up-the-Passkey-Integration-in-Registration), you cannot set up [roommate requests](https://support.cvent.com/s/communityarticle/Managing-Flex-Event-Roommate-Requests) in the registration form. Once an attendee registers and proceeds to book their hotel in Passkey, they can include additional guests during the booking process. Keep in mind the booking data for the additional guests will be associated with the primary guest's record.
