# Importing Hotel Confirmation Numbers in Passkey RezHub

If you are a non-integrated hotel user or a Passkey-licensed organizer, you can use the Hotel Confirmation Number Import tool in [Passkey RezHub](https://support.cvent.com/Passkey/s/communityarticle/Using-Passkey-RezHUB) to upload a list of paired Passkey acknowledgement numbers and hotel confirmation numbers. This helps speed up reservation processing and reduce the number of errors that occur when manually inputting hotel confirmation numbers. You can also use this tool to update hotel confirmation numbers associated with Passkey reservations that have already been processed. 

**1 Retrieve the hotel confirmation numbers.** Obtain a list of paired Passkey acknowledgement numbers and hotel confirmation numbers from the hotel's Sales & Catering, Property Management, or Central Reservation System.

  
 

**NOTE:** The list must be in CSV, TXT, or XLSX format and needs to include at least two columns: one with the Passkey acknowledgement numbers and one with the equivalent hotel confirmation numbers.

  
**2 Access the Hotel Confirmation Number Import tool.** Hover over Reservations in the top navigation, then click **RezHub Delivery**. 

Or, begin by selecting your Passkey event. On the Event Overview page, under Frequent Tasks, click **RezHUB Delivery**.

The RezHub tool will open in a separate browser window.

Click **Import confirmation numbers** in the top-right.**3 Import the hotel confirmation numbers.** If you want to, you can download a spreadsheet template and use it to prepare the list of paired Passkey acknowledgement numbers and hotel confirmation numbers.

Once you have your import list ready, click **Choose file**.

![The "Choose file" button is selectedin the Confirmation Number Import tool.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui0000007Nsj&feoid=00N2G00000CxUw1&refid=0EMUi000005cX06)

Locate the import list on your computer or network, then click **OK** or **Open**.

Click **Next** in the bottom-right to upload the data.

  
 

Use the available dropdowns to map the Passkey Acknowledgement Number and Hotel Confirmation Number headers with the equivalent column headers in the uploaded spreadsheet. 

**NOTE:** If you have used the spreadsheet template available in the first step of the import workflow, the headers will be automatically mapped.

![Mapping page showing the Passkey Ack Number and Hotel Confirmation Number fields being mapped to the corresponding column headers from the import spreadsheet.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui0000007Nsj&feoid=00N2G00000CxUw1&refid=0EM2G0000022TbX)

  
Click **Next**, then **View details** to review the mapped fields.

If any mapping errors are found, click **View details**, then **Export the records with errors**. Save the file to your computer or network, then access it to view and correct the errors. When you're finished, re-import the corrected list.

Click **Import**, then **Return to RezHUB**. All the records that have been successfully mapped will be automatically marked as processed in RezHub.
