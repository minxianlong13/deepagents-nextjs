# The Complete Guide to the Merchant Account Processing Feature in Passkey

The Merchant Account Processing feature is an optional Passkey module that expands the usage of guarantee types by allowing you to set up and collect advance deposit, processing, and cancellation fees for hotel bookings. If you are a Citywide event organizer, this guide will walk you through what you need to know about setting up merchant accounts and using them in your Passkey event.

Setting Up Merchant Accounts  
Passkey supports [Stripe](https://stripe.com/) and [](https://www.authorize.net/)[Authorize.net](https://authorize.net/) as payment gateways. Review the process of applying for a merchant account and adding it to your organization's Passkey account. 

  
Using Merchant Accounts in Passkey Events  
Learn how to enable a merchant account in a Passkey event, set up or edit guarantee types, and configure deposit, processing, and cancellation fees. 

  
Managing and Tracking Transactions  
Learn how to manually adjust or refund transactions, run Passkey Commerce reports, or disable commerce for a specific hotel participating in your Citywide event.
