# Which fields are synced between Passkey and Registration?

FAQEvent ManagementPasskey

If you have [set up the integration between Passkey and your Registration event](https://support.cvent.com/s/communityarticle/Setting-Up-the-Passkey-Integration-in-Registration), registration fields sync to Passkey when a registrant starts booking their hotel from the confirmation page. The fields include:  
 

-   Last Name
-   First Name
-   Email Address
-   Title
-   Contact Source Id
-   Company
-   Address1
-   Address2
-   Address3
-   City
-   State Code
-   Country Code
-   Postal Code
-   Work Phone
-   Home Phone

  
In turn, Passkey reservation fields sync to your Registration event when a registrant successfully completes their hotel booking. These fields include:  
 

-   Hotel name
-   Hotel address
-   Reservation status
-   Reservation name
-   Room type
-   Room rate
-   Room charge
-   Smoking preferences
-   Accessible room option
-   Number of rooms
-   Check-in date
-   Checkout date
-   Passkey acknowledgement number
-   Created date
-   Last Modified date
