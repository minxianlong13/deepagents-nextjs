# Can a new Passkey booking sync to an existing registration if the initial booking was canceled?

FAQEvent ManagementPasskey

Yes. If an attendee cancels their hotel booking, but keeps their registration to an event [integrated with Passkey](https://support.cvent.com/s/communityarticle/Setting-Up-the-Passkey-Integration-in-Registration), they can initiate a new hotel booking by accessing their existing registration. The new hotel booking will automatically sync with the existing registration and will override the details of the canceled booking.
