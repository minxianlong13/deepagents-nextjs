# Which data tag pulls reservation details from Passkey into an event email?

FAQEvent ManagementPasskeyIntegrations

If you have [set up the integration between Passkey and your Registration event](https://support.cvent.com/s/communityarticle/Setting-Up-the-Passkey-Integration-in-Registration), you can include a registrant's Passkey reservation details in an [event email](https://support.cvent.com/s/communityarticle/Creating-an-Event-Email) by inserting the {\[C-MY HOTEL\]} data tag in the [Email Designer](https://support.cvent.com/s/communityarticle/Using-Data-Tags-in-Event#flexemail). The data tag will display a table with the reservation holder's name, reservation status, check-in and checkout dates, hotel name and address, Passkey acknowledgement number, room type, and number of rooms.
