# Adding a Planner to a Passkey Event

[Watch this video](https://videos.cvent.com/watch/uWtf7AvJrV3E9tVPyJeDoP), or follow the steps below to learn how to add a planner to your Passkey event and configure what they can see and do in the [Planner Portal](https://support.cvent.com/s/communityarticle/Passkey-Planner-Portal-Overview).

**1 Add an event planner**. Begin by selecting your Passkey event. From the Event navigation, click **Planners**, then **Planners**. Click the **Add planner** icon under Event Planners.

On the Add Event Planner page, start by entering the planner's email address in the Email field. If the planner already exists in the system, a **Click here** link will appear allowing you to populate the rest of the planner information fields.

Otherwise, fill in the planner's name, company, phone number, and preferred language.

**2 Configure the planner access.** If necessary, [associate an event connection code to this planner](https://support.cvent.com/s/communityarticle/Enabling-RegLink-in-a-Passkey-Event) so that the Passkey event can be connected to a registration system provider that supports [RegLink integration](https://support.cvent.com/s/communityarticle/About-RegLink).

Select what type of access the planner should have to the Planner Portal. Depending on the planner needs, you can set the following access combinations by using the options in the Dashboard Access and Room List Access dropdowns:

-   **Full Access** and **Allow Direct Updates** - Will allow the planner to [run reports](https://support.cvent.com/s/communityarticle/Running-Reports-in-the-New-Planner-Dashboard), [upload room lists](https://support.cvent.com/s/communityarticle/Uploading-a-New-Passkey-Room-List#EventPlanner), find reservation records, as well as make, edit, or cancel reservations through the [Multi-Room Booking Tool](https://support.cvent.com/s/communityarticle/Using-the-Multi-Room-Booking-Tool).
-   **Full Access** and **Allow Request Updates** - Will allow the planner to [run reports](https://support.cvent.com/s/communityarticle/Running-Reports-in-the-New-Planner-Dashboard), [upload room lists](https://support.cvent.com/s/communityarticle/Uploading-a-New-Passkey-Room-List#EventPlanner), and find reservation records, but not to make, edit, or cancel reservations.
-   **Read Only** - Will only allow the planner to [upload room lists](https://support.cvent.com/s/communityarticle/Uploading-a-New-Passkey-Room-List#EventPlanner) and view key event figures and graphs. The Reservations and Reports options in the [Planner Portal](https://support.cvent.com/s/communityarticle/Passkey-Planner-Portal-Overview) will not be available for them, so they won't be able to run reports, and view or manage reservations.

Toggle "Send Email Now" to **ON** to start customizing your email to the planner. If you want the planner to receive regular email notifications, toggle "Enable Weekly Planner Emails" to **ON** as well.

Click **Save**. If you have enabled the email planner, this will be sent immediately.

**3 Manage the event-level planner settings**. From the Event navigation, click **Planners**, then **Planners Settings**. Decide what the planner will be able to see and do in the Planner Portal:

-   **Send SmartAlert** - Toggle this option to **ON** if you want to allow planners to [set up alerts](https://support.cvent.com/s/communityarticle/Setting-Up-Alerts-in-the-Planner-Dashboard).
-   **Show Original** - Check the box next to this option if you want planners to view the original contracted inventory in the event dashboard. The data will pull from the [original sub-block inventory](https://support.cvent.com/s/communityarticle/Viewing-and-Editing-Your-Original-Inventory#SubBlock).
-   **Show Current** - Check the box next to this option if you want planners to view the event's current block details including pickup and available rooms.
-   **Show # of Available Free Sell Rooms** - If you are using [Free-Sell](https://support.cvent.com/s/communityarticle/Enabling-Free-Sell-in-Sub-Blocks) in your event, check the box next to this option to ensure the pickup percentage and available rooms are correctly displayed on the event dashboard. Enabling this option will also display how many Free-Sell rooms are available for each block. The planner will be able to view this information by accessing an event in the Planner Portal and clicking **View Block & Rates**. The Free-Sell rooms will appear under the Additional Availability section of each block.

Click **Save**.

**NOTE:** The planner will need to [register](https://support.cvent.com/s/communityarticle/Registering-as-a-Passkey-Event-Planner) with the same email address you entered in order to see the event in the [Planner Portal](https://support.cvent.com/s/communityarticle/Passkey-Planner-Portal-Overview).
