# Using the Passkey Home Page

With enhanced search capabilities, dashboards, and event insights, the Passkey home page gives you a quick overview of your housing activity, and acts as an access point to your [events](#SearchEvent), [reports](https://support.cvent.com/s/communityarticle/Which-Passkey-report-should-I-run), [organization](https://support.cvent.com/s/communityarticle/Managing-Your-Organization-Profile-in-Passkey) or [hotel profile](https://support.cvent.com/s/communityarticle/Managing-Your-Hotel-Passkey-Profile), and [reservations](https://support.cvent.com/s/communityarticle/How-do-I-search-for-a-specific-Passkey-reservation).

[Watch an instructional video](https://support.cvent.com/s/communityarticle/Passkey-Overview-and-Home-Page-Training#HomePage), or review the sections below to learn more about the features available on the Home page.

Review Summary Data for Your Account

At the top of the Passkey Home page, you can view a summary of the event and reservation activity in your account as well as revenue insights. 

Select the date range and event category you want to see data for by using the dropdowns at the top of the page.

**NOTE:** The reservation data is based on the reservation creation date.

The summary data is displayed across four widgets:

-   **Events** - Displays the number of Passkey events created within the selected date range. For all the date ranges except Last 30 days and Month-to-date, the Events widget also shows comparisons to the same period in the previous year. This way you can quickly determine if the number of created events has increased or decreased and by how much.
-   **Reservations** - Displays the number of reservations and room nights booked within the selected date range, as well as the number of events they are associated with. For all the date ranges except Last 30 days and Month-to-date, the Reservations widget also shows comparisons to the same period from the previous year. This way you can quickly determine if the number of reservations has increased or decreased and by how much. This widget also shows the reservations' average length of stay (ALOS) and the average daily rate (ADR).
-   **Revenue** - Displays the earnings from the reservations made in the selected date range, as well as the earnings from upsells and extended stays. If you are a hotel user, you can also view any incremental revenue obtained through add-ons.
-   **Reservation Method** - Displays a chart of the reservation methods that were used in the selected date range, such as the booking website, multi-room booking tool, room list, or call center.

Review Alerts

New alerts for events that require your attention can be viewed by clicking the **Notifications** icon in the top-right. [Reference this article](https://support.cvent.com/s/communityarticle/What-does-this-alert-on-my-Passkey-Home-page-mean) to learn more about the types of alerts you might find in the Notifications panel.

Search For Events

In the Events section of the Passkey Home page, you have access to multiple filters to help you find specific events. 

To search for an event by name, type the event name in the "Search all events" field, then press Enter on your keyboard. If necessary, you can use the "Search by" dropdown to look for an event by Grouplink code or Event ID instead.

Click **Advanced options** if you need to apply additional search filters such as specific date ranges, event type or status, planner name or email, event location, or hotel name.

The search results will be sorted by the events' start date, but you can use other column headers, such as Event Name or Cutoff, to sort the list per your needs. Additionally, you can click the **Total Nights** column header and toggle between viewing Total Nights or Peak Nights.

Review the Events List

By default, the Events section on the Passkey Home page displays a list of events you've recently viewed, with the last accessed event showing up at the top of the list. You can use the "View by" dropdown to view all the events in your account, events you've created, or events you've marked as favorites.

The event list displays additional details such as the event owner, start date, cutoff, or assigned planners. It also provides pickup and revenue figures you can quickly review.

**NOTE:** Inventory numbers such as pickup and web pickup percentages are updated every two hours, while revenue numbers are updated nightly.

You can quickly mark an event as a favorite by clicking the **Favorite** icon to the right.

Clicking the **Menu** icon to the right of an event gives you access to various options, such as getting a quick overview of your event performance, viewing and managing the booking website, viewing and uploading room lists, or accessing [RezHub](https://support.cvent.com/s/communityarticle/Using-Passkey-RezHUB).

Create Passkey Events

If you have a Passkey license, you can use the **Create new event** button on the Home page to begin [setting up Passkey events](https://support.cvent.com/s/communityarticle/How-do-I-create-an-event-in-Passkey).
