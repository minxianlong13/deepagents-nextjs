# Customizing Your Passkey Website per Attendee Type

Follow the steps below to create a unique online booking experience for your guests, based on their Passkey attendee type.

**1 Select the attendee type.** Begin by selecting your Passkey event. From the left-hand navigation, click **Website**, then **Event Website**.

Under Customize Website, select the attendee type you need from the dropdown.  
 

![Attendee type dropdown, with the General View selected as the default option.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui0000003m05&feoid=00N2G00000CxUw1&refid=0EM2G000003TZze)

If this is the first time you are customizing the booking website for the selected attendee type, click **OK** in the next prompt.

**2 Customize the website for the selected attendee type.** Click **Advanced** in the upper-right, then start customizing the [website images](https://support.cvent.com/s/communityarticle/Managing-Images-on-the-Passkey-Booking-Website), [text](https://support.cvent.com/s/communityarticle/Managing-Text-Elements-on-the-Passkey-Booking-Website), [global font](https://support.cvent.com/s/communityarticle/Setting-a-Booking-Website-Global-Font), and [colors](https://support.cvent.com/s/communityarticle/Customizing-the-Booking-Website-Colors) per your needs.

**NOTE:** The [Splash page](https://support.cvent.com/s/communityarticle/The-Complete-Passkey-Booking-Site-Experience#PK_Web_Splash) cannot be customized by attendee type as this page is displayed before an attendee type is selected.

  
To start customizing another attendee type, simply select it from the first dropdown under Customize Website.If you want to apply the same customization to another attendee type, select the attendee type you want from the first dropdown, then select the attendee type whose customization you want to copy from the second dropdown. Click **Apply**.  
 

![Animation showing how to apply an existing customization to another attendee type.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui0000003m05&feoid=00N2G00000CxUw1&refid=0EM2G000003Ta0m)

  
To revert an attendee type to the default website, select it from first dropdown, then select **General View** from the second dropdown. Click **Apply**.
