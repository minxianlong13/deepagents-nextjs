# Using Passkey RezHub

RezHub is a reservation transfer tool that allows hotels to securely retrieve reservations for Passkey events.

For hotels with [GroupLink integration](https://support.cvent.com/s/communityarticle/Setting-Up-GroupLink-for-a-Passkey-Event), the most common use for RezHub is to [troubleshoot and fix rejected (unprocessed) reservations](#Troubleshoot) so they can be successfully transferred to the hotel's property management system (PMS) or central reservation system (CRS).

For non-integrated hotels participating in Citywide events, RezHub allows you to [retrieve a list of unprocessed reservations](https://support.cvent.com/s/communityarticle/Using-the-RoomList-Download-Feature) to manually add them in the hotel's PMS or CRS. It also provides an [import tool](https://support.cvent.com/s/communityarticle/Importing-Hotel-Confirmation-Numbers-in-Passkey-RezHUB) that helps speed up the process of uploading and associating hotel confirmation numbers to corresponding Passkey reservations.

**NOTE:** For hotels participating in Citywide events, reservations will start populating in RezHub on the [Reservation Access Date](https://support.cvent.com/s/communityarticle/Key-Dates-and-Times-in-Passkey-Events#PK_Hotel_inv_dates).

[Watch this video](https://videos.cvent.com/watch/TX2Mu6sCA8yYp9AuwTGb6y), or follow the steps below to learn how to process reservations through RezHub.

**1 Access RezHub from the Passkey Home page.** Begin by hovering over Reservations in the top navigation, then click **RezHub Delivery**. RezHub will open in a new browser window.

**Or, access RezHub from a specific event.** Begin by selecting your Passkey event. On the Event Overview page, under Frequent Tasks, click **RezHUB Delivery**. RezHub will open in a new browser window.

**2 Search for unprocessed reservations.** By default, RezHub will display a list of unprocessed reservations (if any). Depending on whether you accessed RezHub from the Passkey Home page or a specific event, the list will show unprocessed reservations for all events or for the specific event you have accessed. If you need to refine the list, use the desired search options under Reservations, then click **Search**.

**3 View reservation details.** To view more details about a single reservation, click the **Info** icon to its right.

To view more details about multiple reservations, check the boxes next to the reservations you want, then click **View Details**.

To quickly view why a reservation was rejected, look in the Reason column. This column will display the error that caused the reservation to remain unprocessed. Hover over an entry in the Reason column to view the entire error message. Use the **here** link to access the Knowledge Base where you can search for guides on how to fix the error.

**4 Edit a reservation or the GroupLink setup from RezHub.** To edit a reservation from RezHub, click the acknowledgement number link next to it to open its [Call Center form](https://support.cvent.com/s/communityarticle/Understanding-the-Call-Center-Reservation-Form-in-Passkey). Make any changes you need, then click **Update Res** and **Close Window** at the bottom of the form.

To edit the event's GroupLink setup from RezHub, click the **Edit GroupLink Setup** icon in the Action column. The GroupLink Setup page will load in the browser window or tab where your Passkey application is open.

**5 Process reservations.** Check the boxes next to the reservations you need, then click **Process Reservation**.

For integrated hotels, clicking this button will resend all the selected reservations to the hotel's PMS or CRS for processing.

For non-integrated hotels, you should use this option after the hotel confirmation number generated within the hotel's PMS or CRS was added for each Passkey reservation in RezHub.

**6 Download your reservation details.** Check the boxes next to the reservations you need and click **Print Report**.

Set the Destination to **Save as PDF** to download a report of the reservation details.

Click **Save**.
