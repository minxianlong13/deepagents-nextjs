# Understanding the Call Center Form in Passkey

Topic HubVideoPasskey

The call center form helps you manage Passkey reservations on behalf of your attendees. As you gather the necessary information from your attendees via phone or email, you can use the call center form to [create new bookings](https://support.cvent.com/Passkey/s/communityarticle/Using-the-Call-Center-Form-to-Make-a-Passkey-Reservation) and [modify or cancel existing ones](https://support.cvent.com/Passkey/s/communityarticle/Using-the-Call-Center-Form-to-Modify-or-Cancel-a-Passkey-Reservation).

Navigating the Form  
The call center form consists of three frames:

-   **The left frame** is used for entering the reservation details. You can navigate through the reservation fields either by using your mouse cursor or the TAB key to move from one field to the next.

![Call center form left frame as displayed during the creation of a new reservation.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui0000003iVx&feoid=00N2G00000CxUw1&refid=0EM2G000002hQaM)

-   **The top-right frame** - displays options you can choose from when selecting a specific field in the left frame. For example, if you click inside the Type field in the Event section, the top right frame will display a list of attendee types you can choose from.

![](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui0000003iVx&feoid=00N2G00000CxUw1&refid=0EM2G000002hQaW)

-   **The bottom-right frame** -  displays additional information about specific options in the top right frame. You can easily recognize the options that display additional information as they appear as hyperlinks. For instance, clicking the name of an attendee type option in the top right frame will display room block information for that specific attendee type, in the bottom right  frame.

![](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui0000003iVx&feoid=00N2G00000CxUw1&refid=0EM2G000002hQab)

Understanding the Option Lists  
While all the fields in the left frame accept text input, some of them trigger option lists to appear in the top-right frame. This way, you can either fill in the field manually, or you can select an option from the list to speed up the reservation process and minimize the risk of errors. The option lists can be:  
 

-   **Hyperlinked** - Each option in the list is a hyperlink that can be selected by simply clicking on it (examples include the option list triggered by the Type, Hotel/Room, or the Preferred Language field).

![Animation showing how to select an attendee type by clicking the desired attendee type link from the top-right frame.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui0000003iVx&feoid=00N2G00000CxUw1&refid=0EM2G000002hQaq)

-   **Numbered** - Each option is preceded by a number. In order to select one, enter the option number in the respective field. Numbered option lists are triggered by various fields such as Title, Country, or CC Type.

**NOTE:** To narrow down a list of options, you can start typing in the name of the desired option.
