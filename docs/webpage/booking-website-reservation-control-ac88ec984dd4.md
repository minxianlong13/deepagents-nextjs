# Booking Website Reservation Control

When managing housing for your event attendees, it is important to control what rooms they can book in order to improve pickup rates and provide a seamless booking experience for your guests. Reference the suggestions below to find out what options Passkey has to offer when it comes to managing reservations on the booking website.

Use Access Codes  
By [enabling access codes](https://support.cvent.com/Passkey/s/communityarticle/Enabling-Access-Codes-for-Attendee-Types-in-Passkey) for a specific attendee type, you ensure that the guests who use it will no longer need to select the attendee type for themselves. Moreover, the guests will only view the sub-blocks they are meant to view. This is particularly important if the sub-blocks have special negotiated rates.

Alternatively, you can enable access codes to [hide a specific attendee type](https://support.cvent.com/Passkey/s/communityarticle/How-do-I-hide-an-attendee-type-on-the-Passkey-booking-website). When an access code is enabled, the attendee type in question no longer appears in the attendee type selection dropdown on the Passkey event website. Unless guests have the access code, they won't be able to select that particular attendee type.

Update the Sell Status  
You can tweak the Passkey [sell status](https://support.cvent.com/Passkey/s/communityarticle/Updating-the-Sell-Status) to specify whether guests can book rooms via the booking website, modify their existing reservations, or make reservations via Call Centers. If reservations via Website and Call Centers are restricted, then bookings will need to be made on behalf of attendees by event planners or organizers.

Use Custom URLs  
If you want to ensure guests have direct access to the correct booking flow without using access codes, you can create [custom URLs](https://support.cvent.com/Passkey/s/communityarticle/Creating-Custom-Booking-Website-URLs) for each attendee type. These can then be sent to your guests through campaign emails. When guests access the custom URL, they will be taken straight to that specific attendee type landing page, where they can start making their reservations.
