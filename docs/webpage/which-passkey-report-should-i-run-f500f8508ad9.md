# Which Passkey report should I run?

FAQPasskey

Begin by clicking **Reports** in the top navigation. Or, to run reports for a specific event, begin by selecting the desired event on the [Passkey Home page](https://support.cvent.com/s/communityarticle/Using-the-New-Passkey-Home-Page), then click **Reports** in the top navigation. Carefully read the description of a report to help you determine which one you need. Select the desired report by clicking its name. Some of the most popular reports [you can run](https://support.cvent.com/s/communityarticle/Your-Guide-to-Running-Reports-in-Cvent#Run) are:   
 

-   **Account Usage Overview** - Provides a high-level overview of your events, reservations, revenue, and upsell for your organization, hotel, or sister property organization. [Reference this article](https://support.cvent.com/s/communityarticle/Running-the-Account-Usage-Overview-Report) to learn more about this report.
-   **Block and Pickup** - Returns inventory and pickup data for the hotel room blocks, such as the original contract, current block, and the number of reserved, available, and waitlisted rooms. [Reference this article](https://support.cvent.com/s/communityarticle/Running-the-Block-and-Pickup-Report) to learn more about this report.
-   **Campaigns and SmartAlerts** \- Provides data related to email communications such as [campaigns](https://support.cvent.com/s/communityarticle/Managing-Campaign-Emails), [acknowledgement emails](https://support.cvent.com/s/communityarticle/Managing-Passkey-Acknowledgement-Emails), [hotel communications](https://support.cvent.com/s/communityarticle/Communication-Methods-in-Passkey#PK_HotelComm), and [SmartAlerts](https://support.cvent.com/s/communityarticle/Managing-SmartAlerts-in-Passkey). This report include details such as when an email was sent, when it was read, how many times it was read, and if any links were clicked.
-   **Commerce by Reservation** - Provides a summary of reservation data and commerce details such as invoiced processing, deposit, and cancellation fees, refunds and charges, and reservation balances for all hotels, attendee types, or sub-blocks in an event. 
-   **Cross Event Summary** - Can be run for a specific event or for all events created or starting within a set date range. It helps you audit your events setup by letting you know if any campaigns, SmartAlerts, or scheduled tasks were enabled, or if any event planners were assigned. Additionally, it provides an overview of your events' current block, inventory at peak, and revenue, as well as the total number of reservations.
-   **Delegate** - Displays reservation details such as the primary guest name, stay dates, room and attendee types, the acknowledgement number, or reservation status. Each additional guest is displayed on a separate row. For reservations within a [group booking](https://support.cvent.com/s/communityarticle/Using-Group-Bookings-in-Passkey), the master acknowledgement number and the booking contact's name are also included.
-   **Event Activity** - Provides reservation activity information for a specific event or date range. It includes data such as gross new reservations, room nights, and revenue, modified and cancelled reservations, [no shows](https://support.cvent.com/s/communityarticle/Passkey-Glossary#N), as well as net new rooms, reservations, room nights, and revenue.
-   **Event Setup Summary** - Helps you audit your event settings at all levels, including hotel and sub-block levels.
-   **Registration** - If you [enabled RegLink](https://support.cvent.com/s/communityarticle/Enabling-RegLink-in-a-Passkey-Event) in your Passkey event, you can run the Registration report to view both registration and housing details for your event's attendees. [Reference this article](https://support.cvent.com/s/communityarticle/What-data-can-I-see-in-the-RegLink-report) to learn more about this report.
-   **Room List** - Pulls complete reservation details, including guest information, room types and rates, special requests, billing and travel details, or room share information. Unlike the Delegate report, any additional guests are shown on the same row as the primary guest. [Reference this article](https://support.cvent.com/s/communityarticle/Running-Room-List-Report) to learn more about this report.
-   **Wait List** - Pulls data for reservations that have one or more waitlisted nights.

**NOTE:** To see which classic Passkey reports were consolidated into redesigned reports, [reference this guide](https://community.cvent.com/solution-evolution/passkey-reporting-resources).
