# Running the Account Usage Overview Report

The Account Usage Overview report provides valuable insight into your events, reservations, revenue, and upsell for your organization, hotel, or sister property organization (SPORG). Follow the steps below to run this report and review its data.

**1 Access the report.** Begin by clicking **Reports** in the top navigation, then, under Report Templates, click **Account Usage Overview**.

**2 Run the report.** From the first dropdown, select the year you want to focus on. 

From the the second dropdown, select the desired month.

Under Time Period, select:  
 

-   **Month** if you only want to pull data for events and reservations created during the month you selected.
-   **Year to a month** if you want to pull data for events and reservations created from the start of the selected year up to (and including) the selected month. For example, if you selected 2022 in the Year dropdown and June in the Month dropdown, the Year to Month period will pull data from January 1st, 2022 up to June 30th, 2022.

![Time period parameters selected for the report.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui0000002101&feoid=00N2G00000CxUw1&refid=0EM2G000002iFrr)

  
Select the desired currency, and specify if you want to include data for canceled events.

Click **Run** when you're done.

 

![Example of Currency parameter set to USD, with the option to not include data for canceled events selected. The Run button is highlighted.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui0000002101&feoid=00N2G00000CxUw1&refid=0EM2G000003U6UP)

  
**3 Review the data.** The Account Usage Overview report displays a snapshot of the data recorded at the end of the month selected in the report parameters. Depending on whether the report was run for a hotel, SPORG, or organization, the data will be displayed as follows in the report's grid widget:  
 

-   **For a hotel** - up to three rows: one for events created by the hotel, one describing the hotel's participation in Citywide events created by third-party organizations, and one describing the hotel participation in Citywide events created by a SPORG the hotel is associated with.
-   **For an organization** - one row for events created by the organization.
-   **For a SPORG** - one row for events created by the SPORG and additional rows for each sister property.

  
The report also includes several summary widgets displaying gross data such as events created, reservations, or revenue.
