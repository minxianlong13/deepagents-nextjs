# The Complete Guide to Integrating Registration Events with Passkey

Topic HubEvent ManagementPasskey

The integration between Registration and the Passkey room block management tool allows you to create a unified process that invitees can use to register for your event and book a hotel room. 

Why should I use it?

By linking a Registration event with a Passkey one, you ensure that:

-   Registrants can proceed to booking a hotel room straight after registering for the event. This way, they are more likely to book rooms in the contracted block and benefit from the rates you negotiated.
-   Registrants' [personal details sync to the hotel booking form](https://support.cvent.com/s/communityarticle/Which-reservation-fields-are-synced-between-Passkey-and-Registration) so they don't need to enter the same information twice.
-   Registrants can modify both their registration and hotel booking from the registration confirmation page.
-   [Registration and reservation data is available in the attendee records](https://support.cvent.com/s/communityarticle/Why-is-my-attendees-booking-data-not-showing-up-in-their-Cvent-registration-record) within the Registration event.
-   Registration and reservation data is available in [event-level Travel reports](https://support.cvent.com/s/communityarticle/Reporting-on-Your-Event).

For additional information, [reference this list of frequently asked questions](#FAQ).

  
How do I set up the integration?  
Integrating your Registration event with Passkey has three essential components:

-   [Creating a Corresponding Passkey Event](https://support.cvent.com/s/communityarticle/How-do-I-create-an-event-in-Passkey)**[](https://support.cvent.com/s/communityarticle/How-do-I-create-an-event-in-Passkey)****[](https://support.cvent.com/s/communityarticle/How-do-I-create-an-event-in-Passkey)** - If you have a Passkey license, you can create the Passkey event yourself. Otherwise, the event can be created at [no extra cost for you](https://support.cvent.com/s/communityarticle/RegLink-for-Meeting-Planners#Cost) by a Passkey licensee that can be the contracted hotel or a third-party organization.

![Successful event creation prompt in Passkey](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui000000G1sz&feoid=00N2G00000CxUw1&refid=0EMUi000002YvAo)

-   [Enabling RegLink in the Passkey Event](https://support.cvent.com/s/communityarticle/Why-isn-t-Passkey-syncing-with-my-Cvent-event)**[](https://support.cvent.com/s/communityarticle/Why-isn-t-Passkey-syncing-with-my-Cvent-event)** - This makes the Passkey event available for linking with your Registration event. If you don't have access to the Passkey event, ask the Passkey licensee who created the event to enable this setting for you.

  
![Cvent Events added and enabled as a registration provider in a Passkey event.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui000000G1sz&feoid=00N2G00000CxUw1&refid=0EM2G000003UX1A)

-   [Setting Up the Passkey Integration in Your Registration Event](https://support.cvent.com/s/communityarticle/Setting-Up-the-Passkey-Integration-in-Registration)**[](https://support.cvent.com/s/communityarticle/Setting-Up-the-Passkey-Integration-in-Registration)** - This enables your Registration event for Passkey integration and connects it to the corresponding Passkey event.
