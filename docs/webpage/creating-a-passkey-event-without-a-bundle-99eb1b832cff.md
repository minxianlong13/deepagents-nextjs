# Creating a Passkey Event without a Bundle

If you don't want your Passkey event to have any preconfigured settings or features, you can create a new event without a bundle. Here's how.

**NOTE:** You must have a Passkey license to create events.

**1 Create an event.** On the Passkey Home page, click **Create new event**.

If you are creating an event as a Sister Property Organization (SPORG) representative, specify whether one or multiple hotels take part in the event. For single-property events, select the desired sister property.

Enter the event name and, if applicable, the Grouplink code. 

Set the event start and end dates, then select an event type from the dropdown.

Click **Select** next to "Create your event from scratch," then click **Create event**.

In the next prompt, click **Continue with event setup**.

**2 Manage the event settings.** In the Settings tab of the event setup, you can manage the default settings for your event. These include:

-   **Inventory Dates** - Set the event dates, contracted nights, and shoulder nights.
-   **Reservation Dates** - Set the dates when reservations can be made. You can set different dates for web and call center reservations. If you are a hotel user, you can also use this section to start assigning users to your event.
-   **Venue Information** - If you are a Citywide event organizer you can use this section to enter the address of the event venue and to start assigning users to your event.
-   **Projected Pickup for the Event** - If desired, enter the estimated pickup percentage as the event start date approaches.

**3 Manage the advanced event settings.** Click **Open Advanced Event Settings** to access and customize the following options:

-   **Earned Complimentary Rooms** - Enable this option to track complimentary rooms earned by the meeting planner.
-   **Event Language and Currency** - The default locale of the event determines the primary language used to register attendees. Select additional locales, if desired.
-   **Event Contact Information** - Add contact information that guests can use  if they need additional information about the event.
-   **Wait List** - By enabling this option you allow waitlists to be created for this event.
-   **Additional Booking Options** - Use this section to manage specific reservation settings such as [blank or partial addresses](https://support.cvent.com/s/communityarticle/Enabling-Blank-or-Partial-Addresses-in-Passkey), [rewards program fields](https://support.cvent.com/s/communityarticle/Adding-Rewards-Programs-in-Passkey), or the [group booking workflow](https://support.cvent.com/s/communityarticle/Enabling-Group-Bookings-in-Passkey).
-   **Event Call Center Notes** - Enter notes that users of the Call Center form will see when making reservations.

Click **Next**.

**4 Add inventory.** Add the room inventory associated with the event. If you are an organizer user, you can add inventory for several hotels in order to create a Citywide event. If you are a hotel user, you can only add inventory for your hotel.

Once you select or add the room blocks and attendee types you need, you can create sub-blocks by specifying which attendee types have access to which room types.

For each room block you added, use the Original Block row to enter the number of available rooms for each inventory night, then specify the nightly rate.

For multi-hotel events you can manage the hotel email notifications. These include:

-   **Reservation email notifications will be sent to this hotel. Please click here to update email address.** Clicking this message displays the email addresses specified in the hotel profile. Editing the notification emails for this event will not modify the email addresses in the hotel profile.
-   **Warning! Hotel reservation email address must be set. Please click here to set email address.** This message indicates that there are no email addresses set up in the hotel profile. It is recommended to add at least one email address so the hotel can receive notifications about your event.
-   **Hotel is GroupLink integrated for 1-Way reservation transfer to the hotel system.** This message indicates that the hotel will receive notifications whenever there are reservations that haven't transferred from your Passkey event to the hotel system.
-   **Hotel is GroupLink integrated for 2-Way reservation transfer to the hotel system.** This message indicates that reservations can transfer both outbound (from Passkey to the hotel system) and inbound (from the hotel system to your Passkey event). The hotel will receive notifications whenever there are reservations that haven't transferred from your Passkey event to the hotel system.

Click **Next**.

**5 Add communications.** Check the boxes next to the [communication emails](https://support.cvent.com/s/communityarticle/Communication-Methods-in-Passkey) you want to add to your event. You can also enable them so that they are sent. We recommend leaving them disabled until you complete your changes to the event.

Click **Next**.

**6 Add SmartAlerts.** Check the boxes next to the [alerts and updates](https://support.cvent.com/s/communityarticle/Managing-SmartAlerts-in-Passkey) that should be available in this event. You can also manage the recipients for each of the selected SmartAlerts by clicking the **Manage Recipients** icon.

Click **Next**.

**7 Select the event website template.** Choose the [website template](https://support.cvent.com/s/communityarticle/Managing-Passkey-Booking-Website-Templates) for your event by clicking **Select** under the desired one.

You can also select [add-ons](https://support.cvent.com/s/communityarticle/Managing-Passkey-Add-ons-at-the-Library-Level) and [promo cubes](https://support.cvent.com/s/communityarticle/Managing-Promo-Cubes-at-the-Library-Level) from your library to be added to your event.

Click **Next**.

**8 Add planners.** Fill in the event planner email, name, company, and phone number. Specify if the planner should have full access to the Planner Portal, and if they can make updates to reservations. If you need to designate an additional planner, click **Add Planner** to enter their details.

You can customize and send a notification message to your newly added planners. This message includes a direct link to the Planner Portal, allowing them to access your event straight away.

Based on whether you want to notify the assigned planners of your event, click **Complete and Send Planner Email** or **Complete and Do Not Send Planner Email**.

You can now access your newly created event to further customize its settings.
