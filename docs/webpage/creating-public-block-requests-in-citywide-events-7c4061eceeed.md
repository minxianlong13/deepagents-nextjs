# Creating Public Block Requests in Citywide Events

If you are a Citywide event organizer, public block requests allow you to survey planners on their housing needs and allocate inventory accordingly. Unlike [sub-block requests](https://support.cvent.com/s/communityarticle/Creating-Sub-Block-Requests-in-Citywide-Events), the public block requests you create can be used by individuals who are not Passkey users or not even planners by trade (e.g. sports team coaches, tour operators, or teachers). Depending on how you want to allocate inventory, you can create:

-   [requests where you manually allocate inventory](#Manual).
-   [requests where inventory is automatically allocated from available Free-Sell](#Automatic).

For the latter, you can also set up an approval process to ensure you [have the final say](https://support.cvent.com/s/communityarticle/Approving-a-Public-Block-Request) in the Free-Sell inventory allocation.

Creating Public Block Requests with Manual Inventory Allocation

**1 Add a new public block request.** Begin by selecting your Passkey event. From the Event navigation, click **Sub-Block Group Management**, then **Sub-Block Requests**.

**NOTE:** Don't see this option? [Create a case](https://support.cvent.com/s/createcase) to have sub-block requests enabled for your account.

Click **Add New Sub-block Request**.

Name your request, select "Anyone with a link," then click **Create**.

**2 Configure the request settings.** In the Request Type section, select:

-   **Rooms per night** - If you want public planners to submit their total inventory needs without specifying a hotel.
-   **Rooms per night by hotel** - If you want public planners to request rooms in specific participating hotels.

If you choose the latter, use the Hotel Options section to select the participating hotels that will be presented to planners.

If necessary, use the **Add a hotel** option to include additional hotels.

In the Request Criteria section, you can toggle the desired request options to **ON**. If you enable the Price Range, Hotel Type, or Room Preferences criterion, you can set up multiple options planners can choose from. Enter each option you want planners to see, then click **Add**. You can also re-purpose these three criteria by clicking the **Edit** icon next to them and changing their name per your needs.

To display specific instructions for planners, toggle "Customize Instructions" and "Customize Receipt Instructions" to **ON**, then click the **Edit** icon next to the text box to type in the desired message.

If you want to allow planners to enter their own comments in the request, toggle "Free-text preferences" to **ON**.

If you [enabled a merchant account in your event](https://support.cvent.com/s/communityarticle/Setting-Up-Deposit-Processing-and-Cancellation-Fees) and you want to collect [deposit funds for sub-block groups](https://support.cvent.com/s/communityarticle/Managing-Deposit-Funds-for-Sub-Block-Groups), toggle "Enable credit card collection" to **ON** to allow public planners to enter their credit card details on the public block request form. You can also add custom instructions for the collection of credit card details.

**NOTE:** If your event uses [guarantee rules](https://support.cvent.com/s/communityarticle/Passkey-Guarantee-Rules), and you want to collect deposit funds for sub-block groups, we recommend selecting **Rooms per night by hotel** in the Request Type section of the request setup. Then, under Hotel Options, make sure you only select hotels that are associated with a non-credit card guarantee rule.

In the Request Settings section, you can repurpose the Organization field label to something else, such as Team or Company.

By default, all sub-blocks associated with a sub-block group are closed to reservations until the planner accepts the room allocation. If you want to allow reservations in the sub-blocks before the allocation is accepted, toggle "Close to web until planner accepts" to **OFF**.

You can further personalize the request form by enabling the display of event and organization logos.

If you switch "Display event logo" to **ON**, the Event Logo image you uploaded in your [website customization](https://support.cvent.com/s/communityarticle/Managing-Images-on-the-Passkey-Booking-Website) will display in the top-left corner of the request form.

If you switch "Display organization logo" to **ON**, the logo image you uploaded in your [organization profile](https://support.cvent.com/s/communityarticle/Managing-Your-Organization-Profile-in-Passkey) will display at the bottom of the request form.

Click **Next**.

**3 Set up dates, milestones, and notifications.** Enter the dates that will determine the life cycle of the public block request process:

-   **Request Date Range** - Select the inventory dates for which planners can request rooms.
-   **Publish On** - Enter the date when the request form will become available to planners.
-   **Deadline** - Enter the last date when planners can fill out the survey.
-   **Allocation** - Optionally, enter the date when you expect to complete the room allocation for the event.

Click **Save**.

Once the dates are set, you can set up a notification to be sent out to the public planners. Click **Add** next to Request Allocation. Choose from existing library templates or [create a new notification](https://support.cvent.com/s/communityarticle/Managing-Campaign-Emails#NewCampaign) by clicking **New Campaign**.

Click **Preview request site** to see what the public request form will look like to planners.

Click **Complete**.

**4 Make the survey link available to public planners.** Locate the newly created request on the Sub-block Requests page, then click the **Menu** icon next to it, and select **Copy Survey Link**.

Post the survey link on your website, or share it via email and social media.

Public planners will be able to start submitting requests on the Publish On date you set in the request configuration. 

Once requests start coming in, you can process them by [manually allocating inventory](https://support.cvent.com/s/communityarticle/Processing-Public-Block-Requests-in-Passkey).

Creating Public Block Requests with Automatic Inventory Allocation

**1 Add a new public block request.** Begin by selecting your Passkey event. From the Event navigation, click **Sub-Block Group Management**, then **Sub-Block Requests**.

**NOTE:** Don't see this option? [Create a case](https://support.cvent.com/s/createcase) to have sub-block requests enabled for your account.

Click **Add New Sub-block Request**.

Name your request, select "Anyone with a link," then click **Create**.

In the Request Type section, select **Rooms from available free-sell**. This option will allow public planners to search available Free-Sell rooms and directly request or secure room blocks. In this type of request, the sub-block groups, contacts, and room blocks are instantly created based on validation rules and limits that you impose.

**2 Configure the request settings.** Select the maximum number of requests a public planner can submit. Set "Display number of available rooms" to **Yes** if you want planners to see the actual availability for hotels and rooms, or **No** if you only want to show that a night is available but not how many rooms are left.

Choose whether or not you want to approve a request. If you select **Yes**, each request will need to be reviewed and [approved](https://support.cvent.com/s/communityarticle/Approving-a-Public-Block-Request) by you before the allocated inventory can be used. If you select **No**, each request will be automatically approved and the allocated inventory can be used.

Optionally, rename the Organization field in the public block request.

If necessary, add introductory and confirmation messages to your request.

**3 Configure the attendee type settings.** When a public planner submits a request, a sub-block group is automatically created. The group will be associated with a new attendee type named after the planner's organization, and the planner will be added as the sub-block group contact. Optionally, you can add a prefix to the attendee type name to help you quickly identify and organize the various attendee types that will be created through the public block request.

If your event is configured to assign guarantee types based on attendee types, select the desired [guarantee type](https://support.cvent.com/s/communityarticle/Configuring-Guarantee-Types-in-Passkey-Events) you want to associate to the attendee types created through the request.

Check the boxes next to the options that should apply to the attendee types that are created through the request.

Click **Next**.

**4 Set milestone dates for the request.** Enter the dates that will determine the life cycle of the public block request process:

-   **Dates Available to Request** - Select the inventory dates requesters can choose from.
-   **Publish On** - Select the date when the request form will become available to fill in and submit.
-   **Request Due Date** - Select the last date when requesters can fill in and submit the form.
-   **Release Block To Free-Sell** - Specify until when rooms are held exclusively for the requester. Your options include the [cutoff date](https://support.cvent.com/s/communityarticle/Key-Dates-and-Times-in-Passkey-Events#PK_Cutoff_date), a custom date, or a set number of days after the approval. You can also choose not to release the rooms to Free-Sell.
-   **Allocation Due** - For requests that need approval, you can set an approval deadline date.

Click **Next**.

**5 Add hotels and rooms.** Check the boxes next to the hotels and room types requesters can choose from.

For each inventory night, specify the maximum number of rooms planners can select per request, hotel, and room type.

For example, if you set 20 as the maximum number for the request and 10 for a specific hotel, the planner won't be able to request more than 10 rooms in that hotel. They can, however, request 10 more rooms in another hotel included in the request form, if applicable.

Keep in mind that, ultimately, the maximum number of rooms a planner can select is limited to what is available in [Free-Sell](https://support.cvent.com/s/communityarticle/Enabling-Free-Sell-in-Sub-Blocks) at the time the request is made. For example, if only 10 rooms are left available in Free-Sell, the planner won't be able to select more than 10 rooms even if the request has no set limit (indicated by the ∞ symbol) or a limit larger than 10.

Click **Next**.

**6 Set notifications.** Check the box next to "Allow access to request website via public link" to generate a request URL that you can then post on your website or share via email and social media.

If you want to send a notification email to a specific set of recipients to let them know they can request room blocks, hover over the **No recipients** warning icon next to "Room Block Requests Open," then click **Upload recipient list**.

Download the recipient list template and fill it in with the desired contact details.

When you're finished, click **Browse files**, then select the recipient list from your computer or network.

Click **Upload list**.

To update the email content or date when it should be sent, click the **Edit Notification** icon under Actions. Toggle "Room Block Requests Open" to **ON**.

For requests that require manual approval, a notification email will be automatically sent when you approve a request. You can edit the content of the notification email by clicking the **Edit Notification** icon next to Room Block Approved.

**7 Complete the public block request configuration.** Click **Preview request site** to see what the public request form will look like to planners.

When you're ready, click **Finish**. Your new request will appear under _Sub-Block Group Management > Sub-Block Requests_ as a "Rooms from available free-sell" request type.

Public planners will be able to start submitting requests on the Publish On date you set in the request configuration.

**NOTE:** If you add hotels or room types to your event after the launch of the public block request form, make sure you [edit the request](https://support.cvent.com/s/communityarticle/Can-I-edit-a-public-block-request-after-I-ve-published-it) to include the new hotels or room types in the form.
