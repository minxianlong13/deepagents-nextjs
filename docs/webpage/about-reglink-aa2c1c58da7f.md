# About RegLink

RegLink is a set of open application programming interfaces (APIs) used to securely link online registration solutions to the Passkey hotel reservation system. It allows you to integrate hotel reservations directly into an event's registration process, and it addresses some of the main challenges organizations typically encounter, such as:  
 

-   Pre-populating an attendee's personal information from the registration site to a Passkey booking website.
-   Discouraging attendees from booking outside the contracted block by automatically directing attendees to reserve housing.
-   [Running reports](https://support.cvent.com/s/communityarticle/What-data-can-I-see-in-the-RegLink-report) to track who registered, who booked a room, and who has done both.
-   [Sending email notifications](https://support.cvent.com/s/communityarticle/Managing-Campaign-Emails) (also known as campaigns) to attendees who have registered but have not yet reserved a hotel room to ensure they stay in the contracted block.
-   Increasing early pickup.

  
Can I use RegLink?  
Passkey integrates with most of the [major event registration providers](https://support.cvent.com/s/communityarticle/Which-Event-Registration-Providers-are-Integrated-with-Passkey), and the [RegLink Open APIs](https://developers.cvent.com/documentation#tag/Housing) allow anyone to set up the integration and connect the registration with a Passkey booking website.
