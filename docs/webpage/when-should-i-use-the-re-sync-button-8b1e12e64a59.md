# When should I use the Re-Sync button?

FAQEvent ManagementPasskey

If your event is [integrated with Passkey](https://support.cvent.com/s/communityarticle/Setting-Up-the-Passkey-Integration-in-Registration), you should use the **Re-Sync** button under _Travel > Hotel Accommodations_ whenever attendee types, room types, or participating hotels are added to or modified in the corresponding Passkey event. If attendee types were added to the Passkey event, make sure you also [set the desired mappings](https://support.cvent.com/s/communityarticle/Setting-Up-the-Passkey-Integration-in-Registration#Mapping) for them in the registration event.
