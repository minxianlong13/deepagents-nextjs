# Submitting Registration Connectivity Requests

If you have been [added as a planner to a Passkey event](https://support.cvent.com/s/communityarticle/Adding-a-Planner-to-a-Passkey-Event), follow the steps below to submit a registration connectivity request. This allows a registration event to be connected to the Passkey housing event. Once the two events are connected, attendees can register and book rooms in one seamless session.

**1 Access the Planner Portal.** Go to [planners.passkey.com](https://planners.passkey.com/) and log in with your credentials. Click the name of the event you need.

**2 Submit a registration connectivity request.** From the left-hand navigation, click **Event Registration Integration**. Select the registration system you want from the dropdown.

Click **Request**.Once it is submitted, the request will display a Pending status.

At this point, [users who have been assigned to the event](https://support.cvent.com/s/communityarticle/Assigning-Users-to-a-Passkey-Event) will receive a notification about your request. To view and manage the request, they need to access the event in Passkey and click **Details**, then **API Access**. 

Clicking **Accept** will automatically add and enable the registration provider. The event users will also be prompted to add any default callbacks associated with the selected provider.

**3 Review the response.** Once the event user selects an action, you will receive a notification email letting you know whether your request was accepted or declined.

If your request was accepted, the status of your request will show as "Connected" on the Event Registration Integration page.

If your request is declined, it will be removed from the Event Registration Integration page.
