# Using the Room List Download Feature in RezHub

For hotels that don't have a Passkey integration allowing automatic reservation transfer, you can use the RezHub Room List Download feature to retrieve a list of Passkey reservations that can then be added to a hotel's Sales & Catering system (S&C), Property Management System (PMS), or Central Reservation System (CRS). Here's how.

**1 Access RezHub from the Passkey Home page.** From the top navigation, hover over Reservations and click **RezHub Delivery**. RezHub will open in a new browser window.

**Or, access RezHub from a specific event.** Begin by selecting your Passkey event. On the Event Overview page, under Frequent Tasks, click **RezHUB Delivery**. RezHub will open in a new browser window.

**2 Select the events for which you want to download reservations.** Click **Download room list**. Any room lists you have downloaded in the last 30 days will be listed in the Previously Downloaded Room Lists section of the Download Room List prompt. You can re-download any of them if you need to.

If you've accessed RezHub from a specific event, the event will be selected by default as long as the [Reservation Access Date](https://support.cvent.com/s/communityarticle/Key-Dates-and-Times-in-Passkey-Events#PK_Hotel_inv_dates) has passed.

You can select up to 10 events to download reservations for. If necessary, use the search field above the events list to look for specific events by name. You will only see events that include at least one hotel you have access to and have active reservations.  

**NOTE:** You cannot download reservation data for a hotel in a Passkey event if more than seven days have passed since the hotel's last [inventory date](https://support.cvent.com/s/communityarticle/Key-Dates-and-Times-in-Passkey-Events#PK_Hotel_inv_dates).

Click **Next**.

**3 Select the hotels for which you want to download reservations.** If you are a Citywide event organizer, check the boxes next to the hotels you want to include in the room list download. The hotels you see are the ones associated to the events you selected. 

**NOTE:** If you are a hotel user, you won't be prompted to select hotels since you can only download reservations associated to your hotel, so [skip to the next step](#Res).

Click **Next**.

**4 Choose reservations.** Decide whether you want to include all the reservations marked as Unprocessed in RezHub or only the reservations created or modified since the start of a specific date. We recommend selecting the first option in the list.

Click **Next**.

**5 Download the room list.** Name your download. If you're downloading a room list for a single event, you can select a specific attendee type if desired, or include all the attendee types in the event.

Select the file format for your data. Not sure what to choose? Contact your hotel's management system helpdesk to find out what file format they support.

Enter your Passkey password, then check the box next to "I agree to these terms and conditions." Click **Run**.

Save the room list file to your computer or network.

Carefully read the Notice prompt message, then click **I understand** or **Download again**.

**6 Enter the hotel confirmation numbers in RezHub.** Use the downloaded room list to recreate the Passkey reservations in the hotel's management system and generate hotel confirmation numbers for each. Afterwards, you can add the hotel confirmation numbers in RezHub either [manually](https://support.cvent.com/s/communityarticle/Manually-Processing-Reservations-in-Passkey) or by using the [RezHub Hotel Confirmation Import tool](https://support.cvent.com/s/communityarticle/Importing-Hotel-Confirmation-Numbers-in-Passkey-RezHUB).
