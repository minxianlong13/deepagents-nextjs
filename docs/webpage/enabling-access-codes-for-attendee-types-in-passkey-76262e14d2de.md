# Enabling Access Codes for Attendee Types in Passkey

Ensure certain room blocks are only visible to specific attendee types by setting up access codes. Attendees will need to enter these system-generated or custom codes in order to start making reservations in the respective room blocks.

At the Library Level

**NOTE:** Changes made at the library level will not apply to existing events. To manage access codes in existing events, [skip to these steps instead](#PK_Event_AdvOp_Att_Code).

  
**1 Access your library of attendee types.** Begin by hovering over Manage in the top navigation, then click **Hotel Setup** or **Organizer Setup**.

From the left-hand navigation, click **Libraries**, then **Attendees**. 

**2 Enable access codes.** Locate the attendee type you want to modify and click the ![Edit](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui0000001CvB&feoid=00N2G00000CxUw1&refid=0EMUi000001vdaL) icon to its right. Check the box next to "Require Access Code."  
 

![The "Require Access Code" option is selected in the attendee type settings.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui0000001CvB&feoid=00N2G00000CxUw1&refid=0EM2G000002hT65)

Click **Save**. Back on the Attendees page, the attendee type you modified will now display "Yes" in the Require Access Code column.

At the Event Level

**1 Access the attendee type you want to edit.** Begin by selecting your Passkey event. From the left-hand navigation, click **Advanced Options**, then **Attendee Types**. Click the name of the attendee you want to edit.**2 Enable the Access Code.** Leave the system-generated code or enter a custom one in the Code field, then check the box next to "Access code required for reservation."  
 

**NOTE:** All Access Codes must be unique across all Passkey events. If you want to reuse a code from a previous event, you need to first change the code in the old event to something else.

![The "Access code required for reservation" option is enabled in the attendee type settings.](https://support.cvent.com/servlet/rtaImage?eid=ka0Ui0000001CvB&feoid=00N2G00000CxUw1&refid=0EM2G000002hT6A)

  
Click **Save**.
