# How do I assign a different guarantee type to an attendee type?

FAQPasskey

If your Passkey event is configured to assign guarantee types based on the attendee type rather than the [hotel selected on a reservation](https://support.cvent.com/s/communityarticle/Passkey-Guarantee-Rules), you can change the guarantee type associated with an attendee type. Begin by selecting your Passkey event, then go to _Advanced Options > Attendee Types_. Or, if your account has access to [guarantee rules](https://support.cvent.com/s/communityarticle/Passkey-Guarantee-Rules), select your Passkey event, then, under Event Home, click **Attendee Types**. Locate the attendee type you need, and click the corresponding guarantee type under Assigned Payment Plan. Specify whether or not a guest guarantee is required, then select the desired guarantee type from the "Assign Payment Plan to" dropdown. If the guarantee type you need is not listed, use the **click here** link to [create one](https://support.cvent.com/s/communityarticle/Configuring-Guarantee-Types-in-Passkey-Events).

Click **Save**.
