# Can a Registration event be mapped to more than one Passkey event?

FAQEvent ManagementPasskey

No. The [integration between a Registration event and Passkey](https://support.cvent.com/s/communityarticle/The-Complete-Guide-to-Integrating-Events-with-Passkey) only allows a single Passkey event to be mapped to a Registration event. 

If you have a Passkey organizer license, you can, however, [create a multi-hotel Passkey event](https://support.cvent.com/Passkey/s/communityarticle/Using-a-Bundle-to-Create-a-Passkey-Event) and add all the contracted venues to it. This way you won't need a separate Passkey event for each participating venue, and you can [map the event's open URL](https://support.cvent.com/s/communityarticle/Setting-Up-the-Passkey-Integration-in-Registration#Connect) to your Registration event. 

If you don't have a Passkey license, check if the venues you contracted for your Registration event are sister properties. Depending on their Passkey account, they may be able to set up a multi-hotel event with one open URL that you can map to your Registration event.
