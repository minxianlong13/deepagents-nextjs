# Can I use group registration in an event that is integrated with Passkey?

FAQEvent ManagementPasskey

Yes. [Group registration](https://support.cvent.com/s/communityarticle/Using-Group-Registration) can be used in an event that is [integrated with Passkey](https://support.cvent.com/s/communityarticle/Setting-Up-the-Passkey-Integration-in-Registration). The group leader can add group members and register on their behalf. On the confirmation page, the group leader can then proceed to book hotel accommodations for each group member in turn. Alternatively, once the group members are registered by the group leader, each member can proceed to book their own hotel accommodations by accessing the confirmation page from the registration confirmation email. Make sure you [add the {\[E-MODIFY REG LINK\]} or {\[E-MODIFY REG URL\]} data tag](https://support.cvent.com/s/communityarticle/Using-Data-Tags-in-Event) in the registration confirmation email.
