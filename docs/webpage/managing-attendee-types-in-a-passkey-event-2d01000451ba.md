# Managing Attendee Types in a Passkey Event

In Passkey, you can set up various attendee types to distinguish between who can book specific rooms, what rates they will pay, what payment methods they can use, or what add-ons and promo cubes they will have access to.

Follow the steps below to [create](#PK_event_att_create), [edit](#PK_event_att_edit), or [delete](#PK_event_att_del) attendee types in a Passkey event.

Creating an Attendee Type

**1 Access the Inventory Tasks menu.** Begin by selecting your Passkey event. On the Event Overview page, click the name of the hotel to access the inventory. Hover over Inventory Tasks in the top-right and click **Add Attendee Types**.

**2 Add an attendee type.** To add an attendee type from the library, check the box next to it, choose whether or not to enable it for [Free-Sell](https://support.cvent.com/s/communityarticle/Passkey-Glossary#F), then click **Add**.

If the attendee type you need is not in the library, click **New Attendee**.

Give it a name, then select the [guarantee type](https://support.cvent.com/s/communityarticle/Configuring-Guarantee-Types-in-Passkey-Events) you want to assign to it.

**NOTE:** Don't see an option to select a guarantee type? It means [guarantee rules](https://support.cvent.com/s/communityarticle/Passkey-Guarantee-Rules) were enabled in your event, and guarantee types are assigned based on the hotel selected on a reservation.

Specify if the new attendee type should be [Free-Sell](https://support.cvent.com/s/communityarticle/Passkey-Glossary#F) enabled.

From the Reservations per Session dropdown select the number of rooms an attendee can book at a time. This setting is particularly important if you are using the [group booking feature](https://support.cvent.com/s/communityarticle/Enabling-Group-Bookings-in-Passkey) in your event.

Depending on your event needs, you can enable the following options by checking the boxes next to them:

-   **Access code required for reservation** - Enabling this option will prompt the attendee to enter a unique code in order to start the reservation process on the booking website. Enter a custom code of your own, or leave the Code field blank to have the system generate one for you. The access code can have up to 20 characters and must be unique across your event.
-   **Show link for additional reservations** - Enabling this option will trigger a booking link to display on the Guest Deck page of the booking website once an attendee has successfully completed a reservation. Clicking this link will allow the guest to make additional reservations by taking them back to the first page of the booking website.
-   **This attendee has guaranteed their blocks** - Enabling this option will ensure that any unsold guaranteed rooms will be included in the total pickup.
-   **Roll guaranteed blocks up in reports** - Enabling this option will ensure that any guaranteed blocks will be shown in a single row in Passkey reports, rather than on separate rows for each attendee type.
-   **Configurable on attendee booking site** \- Enabling this option will allow you to [personalize the booking website experience](https://support.cvent.com/s/communityarticle/Customizing-Your-Passkey-Website-per-Attendee-Type) for this specific attendee type.
-   **Add to Library** - Enabling this option will allow you to use this attendee type in future Passkey events.

Click **Add**.

Editing an Attendee Type

**1 Access the Attendee Types page.** Begin by selecting your Passkey event. From the Event navigation, click **Advanced Options**, then **Attendee Types**.

Or, if your Passkey account has access to [guarantee rules](https://support.cvent.com/s/communityarticle/Passkey-Guarantee-Rules), click **Event Home**, then **Attendee Types** in the Event navigation.

**2 Change the assigned guarantee type, if necessary.** Locate the desired attendee type in the list, then, from the Assigned Payment Plan column, click the corresponding guarantee type. 

**NOTE:** Don't see the Assigned Payment Plan column? It means [guarantee rules](https://support.cvent.com/s/communityarticle/Passkey-Guarantee-Rules) were enabled in your event, and guarantee types are assigned based on the hotel selected on a reservation. [Skip to the next step](#Editattendee).

Specify if a guarantee is required for the attendee type. If you selected **Yes**, use the "Assign Payment Plan to" dropdown to change the guarantee type, then click **Save**.

**3 Edit the attendee type.** Click the name of the attendee type you want to edit.

Make any changes to its configuration, such as the attendee type name, number of rooms that can be booked in one reservation, or enabled features.

Click **Save**.

**4 Add access codes, if necessary.** You can have several access codes per attendee type. This is most commonly used when an incorrect access code is given out to attendees to use online. On the Attendee Types page, locate the type you need and click the **add code** icon to its right. Give it a name, then add the desired code. The access code can have up to 20 characters and must be unique across your event.

Click **Save**.

Removing an Attendee Type

**1 Access the Attendee Types page.** Begin by selecting your Passkey event. From the Event navigation, click **Advanced Options**, then **Attendee Types**.

Or, if your Passkey account has access to [guarantee rules](https://support.cvent.com/s/communityarticle/Passkey-Guarantee-Rules), click **Event Home**, then **Attendee Types** in the Event navigation.

**2 Delete the attendee type.** Locate the attendee type you need, then click the **Delete Attendee** icon to its right. Click **OK** to confirm.

**NOTE:** Attendee types with assigned inventory or with any reservation transactions cannot be deleted even if the reservations are canceled and the inventory is completely removed.
